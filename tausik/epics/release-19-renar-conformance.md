Тело релиза 1.9 по решению владельца (сессия #178, решения #254 и #255). Строится ТОЛЬКО по принятым ADR RENAR: 011 (расщепление ADAPT/ACTZ), 012 (AT, изоляция авторства P8, красная история P9), 013 (типы SPEC 9-11). Шесть предложенных ADR — 015, 016, 017, 018, 019, 024 — НЕ реализуются, пока предложены; два из них (017 односторонняя приёмка, 019 опорная версия описания) бьют прямо в контур и в правило инвалидации. Источник сверки — локальный репозиторий standards/renar, ветка v1-1-wave.
