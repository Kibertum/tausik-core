SENAR 1.5 выпущен 07.09.2026 на ветке docs/senar-15 (standards/senar, сабмодуль standard-src @ 245f8a4); 1.4 — на senar.tech с 19.09; публичный GitHub Kibertum/SENAR по-прежнему v1.3 (27.03). TAUSIK заявляет «v1.3 Core и никакую другую» (README, решение #336), при этом матрица соответствия датирована 13.06.2026 (TAUSIK 1.7.0) и относит к «Core» правила Стандарта 9.x (лимит сессии, чекпоинт, аудит), которых в Core нет: SENAR Core 1.5 = 8 правил, Start Gate + Done Gate, «три вещи, делающие гейт гейтом» (a, c, e), две метрики; управление сессиями появляется на Foundation. Дельта 1.4→1.5, касающаяся TAUSIK: 9.4 «Сообщение о показателе» (метод раскрывается с цифрой; самодельные записи меряют записанное; самоустановленный порог несёт основание; пересечение порога эскалируется, а не двигается тихо), 10.15(f) — документированная шкала severity, 4.1 — один признанный случай прямой правки с датированным списком и привязкой к 10.13, 3.45 — определение handoff, 13.1(e) — несоответствия раскрываются вместе с заявлением, 13.7 — механически проверяемые положения. История доводит заявление до редакции, которую можно назвать публично: код матрицы читает корпус стандарта, а не пересказ; детектор дрейфа SENAR строится по образцу renar_standard_drift. Развилка владельца: публичное заявление 1.5 требует ПУБЛИКАЦИИ SENAR 1.5 (сегодня опубликованы 1.3 на GitHub и 1.4 на сайте) — иначе README цитирует неопубликованную редакцию.
