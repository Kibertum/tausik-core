## Goal

Количественный аудит зрелости по 6 осям: 1) Code Quality Score (баги/1000 строк, покрытие тестами %%, lint warnings) 2) Architecture Integrity (layer violations count, dead code %, coupling metric) 3) Test Maturity (tests/module ratio, edge case coverage, mutation-like check) 4) Operational Readiness (bootstrap success rate, onboarding steps count, time-to-first-task) 5) Documentation Freshness (outdated refs count, CLI help coverage %%) 6) Dogfooding Score (framework features used on itself / total features). Каждая ось 0-100, итого composite score. Сравнить с предыдущими аудитами.
