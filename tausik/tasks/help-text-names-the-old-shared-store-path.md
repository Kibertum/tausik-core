## Goal

Решение #222 перенесло общую базу из ~/.tausik/ в ~/.tausik-knowledge/, потому что имя .tausik в домашнем каталоге захватывало обнаружение проекта. Код переехал, СЛОВА остались: восемь мест продолжают называть ~/.tausik/knowledge.db, из них четыре — справка CLI, которую пользователь читает как инструкцию.

tausik memory add --help прямо сейчас советует путь, по которому базы нет. Человек пойдёт туда, ничего не найдёт и решит, что записи не сохранились.

ЧТО ПРАВИТЬ: project_parser.py (4 строки справки: knowledge, decide --global, memory add --global, brain move 'global'), knowledge_db.py:10, knowledge_import.py:7, project_cli_snippet.py:9, service_decide.py:58.

ЧЕГО НЕ ТРОГАТЬ: knowledge_db.py:62 рассказывает историю самого дефекта — «создание ~/.tausik/knowledge.db сделало это». Там старый путь ВЕРЕН как факт прошлого, и замена его на новый превратит верный рассказ в ложный. Это главная ловушка задачи: слепая замена по дереву испортит ровно то место, которое объясняет, зачем был переезд.

КРИТЕРИИ: 1) ни одна строка справки CLI не называет старый путь; 2) путь в справке берётся из константы модуля, а не повторяется литералом — иначе следующий переезд разойдётся снова; 3) НЕГАТИВНЫЙ: исторический абзац в knowledge_db.py сохраняет старый путь, и тест падает, если его заменили; 4) tausik memory add --help показывает тот же путь, который вернёт knowledge_db_path().
