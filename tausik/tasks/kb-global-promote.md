## Goal

Снять когнитивный налог с момента записи. Сейчас решение это кросс-проектное или нет принимается АВАНСОМ, при захвате, и именно это убивает привычку пользоваться общей базой. Вместо этого: писать всё локально как обычно, а когда похожая запись всплыла во ВТОРОМ проекте — предложить повышение. Решение принимается тогда, когда для него появились данные. Похожесть определять дёшево через FTS-кандидаты плюс порог, а не полным попарным сравнением (см. дефект O(n^2) в memory_cleanup). Предложение не должно быть навязчивым: одна строка на старте сессии либо на task done, с возможностью отключить.

## Acceptance Criteria

1. Запись по умолчанию идёт локально; повышение в общую базу НЕ требуется авансом при захвате.
2. При появлении похожей записи во ВТОРОМ проекте система предлагает повышение; тест воспроизводит сценарий «похожая запись всплыла в другом проекте → предложение».
3. Похожесть считается через FTS-кандидатов плюс порог, без полного попарного O(n^2) сравнения.
4. Предложение ненавязчиво: одна строка на старте сессии или на task done, с возможностью отключить.
