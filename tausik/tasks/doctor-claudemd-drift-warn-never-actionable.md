## Goal

tausik doctor каждую сессию печатает WARN «14 static section(s) differ from bootstrap template ... re-run bootstrap to reset». Для ЭТОГО репозитория (сам фреймворк) расхождение ПОСТОЯННО и правильно: CLAUDE.md здесь написан вручную и специфичен, а шаблон bootstrap_templates — общий для поднимаемых проектов. Два дефекта. (1) Сигнал несбрасываемый: предупреждение, которое нельзя погасить законным действием, обучает читателя игнорировать вывод doctor целиком — обесценивается не одна строка, а весь инструмент, и на его фоне потеряется настоящий WARN. (2) Предлагаемая ремедиация РАЗРУШИТЕЛЬНА: 're-run bootstrap to reset' затрёт намеренную кастомизацию, то есть doctor советует потерю данных как штатный шаг. Цель: либо проверка учится отличать намеренную кастомизацию от дрейфа, либо для self-hosted случая не применяется, либо текст перестаёт советовать разрушительное действие. Итог: doctor на здоровом дереве обязан быть ЧИСТЫМ.

## Acceptance Criteria

AC1. Замерено, ЧТО именно расходится: перечислены все 14 секций с указанием, какие расхождения намеренны (кастомизация фреймворкового репозитория), а какие — настоящий дрейф. Без этого замера нельзя выбрать между тремя вариантами решения; догадка о пропорции не принимается.
AC2. Выбран и обоснован один из вариантов: (а) проверка различает намеренную кастомизацию и дрейф по явному маркеру/allowlist; (б) self-hosted репозиторий (сам фреймворк) исключён из проверки по признаку, который нельзя подделать в поднятом проекте; (в) проверка остаётся, но текст перестаёт советовать разрушительное действие. Решение записано через tausik decide с указанием отвергнутых вариантов.
AC3. На здоровом дереве этого репозитория tausik doctor завершается БЕЗ предупреждений (OK, 0 warnings) — проверяется прогоном, а не рассуждением.
AC4. Способность обнаружить НАСТОЯЩИЙ дрейф НЕ утрачена: тест вносит реальное расхождение в статическую секцию и доказывает, что проверка его по-прежнему видит. Глушение предупреждения вместо его починки — провал задачи.
AC5. НЕГАТИВНЫЙ сценарий: если выбран вариант (а) или (б), тест доказывает, что маркер/признак нельзя случайно активировать в обычном поднятом проекте — иначе проверка отключится у всех пользователей вместо одного репозитория.
AC6. Текст ремедиации в любом варианте не предлагает действие, приводящее к потере ручной правки, без явного предупреждения о последствиях.
AC7. Гейты зелёные: ruff, mypy, pytest, filesize. bootstrap.py --ide all после правки source (конвенция #321). CHANGELOG EN+RU.
