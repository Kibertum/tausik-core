## Goal

TAUSIK ставится одним пакетом, который понимают несколько агентских упряжек, а не сборкой из скиллов, MCP-сервера и хуков по отдельной инструкции.

## Acceptance Criteria

AC1. СИГНАЛ (закладка 2026-08-06): появился формат Agent Plugins — скиллы и MCP пакуются вместе стандартным способом, понятным нескольким упряжкам разных вендоров. ПЕРВЫМ ШАГОМ — проверить, что это такое на самом деле, по первоисточнику, а не по пересказу в канале. Закладка — указатель, а не документация.
AC2. НАШ РАЗБРОС ОПИСАН ЧИСЛОМ: сколько частей сейчас ставится и сколько шагов делает пользователь. У нас скиллы, MCP-сервер, хуки и bootstrap — и отдельная известная ловушка про перезапуск IDE.
AC3. СВЯЗЬ С ЭПИКОМ v2-global-mcp НАЗВАНА ЯВНО: там уже идёт переход на глобальную установку вместо сабмодуля. Задача либо ложится в него, либо обязана объяснить, почему отдельно. Две несогласованные схемы поставки хуже одной плохой.
AC4. НЕГАТИВНЫЙ СЦЕНАРИЙ: формат не имеет права стать единственным путём установки, пока он не устоялся. Существующий путь остаётся рабочим, иначе чужой ранний стандарт становится нашей точкой отказа.
AC5. НЕГАТИВНЫЙ СЦЕНАРИЙ: если формат покрывает не всё, что мы ставим (хуки, гейты, bootstrap), непокрытое называется поимённо, а не замалчивается наполовину сделанной упаковкой.
AC6. Проверить заодно, решает ли упаковка нашу ловушку со старым кодом MCP после обновления. Если нет — сказать это прямо, чтобы никто не ждал.
