## Goal

Найдено адверсариальным ревью сессии #132 сразу ПОСЛЕ закрытия bash-c-wrapper-bypasses-qg0-write-gate — то есть на фикс находки, как требует конвенция #276. `write_targets("env bash -c 'echo x > e.py'")` возвращает `[]`: рекурсия в payload срабатывает по `basename(sub[0])`, а первым токеном стоит `env`, а не оболочка. Те же формы: `sudo bash -c`, `nohup bash -c`, `timeout 5 bash -c`, `stdbuf -o0 sh -c`, `nice bash -c`. Это ровно тот класс однострочного обхода Rule 1 и scope-ACL, который только что закрыт для голого `bash -c`, просто на уровень выше — префикс несёт настоящую команду в своих аргументах. `env bash -c` обфускацией не является. Направление: перед определением base пропускать известные транспарентные префиксы (env с его VAR=val аргументами, sudo с флагами, nohup, timeout с длительностью, nice, stdbuf, ionice) и брать первый токен, который не является префиксом и не имеет формы VAR=val. Осторожно: `sudo tee` уже назван в остаточной границе как непойманный писатель за обёрткой — пропуск префиксов закроет и его, это желаемое следствие, но требует прогона на false-positive.

## Acceptance Criteria

1. Воспроизведение ДО фикса: `env bash -c 'echo x > e.py'`, `sudo bash -c '...'`, `nohup bash -c '...'`, `timeout 5 bash -c '...'` дают ноль целей.
2. Транспарентные префиксы пропускаются ОДНИМ механизмом, используемым и для рекурсии в оболочку, и для определения писателя (tee/dd/sed/cp): `sudo tee f` обязан находиться так же, как `tee f`.
3. `env VAR=val bash -c '...'` — токены вида VAR=val пропускаются вместе с префиксом.
4. NEGATIVE, никаких новых false-positive: `env` без команды, `sudo -v`, `timeout --help`, `nice`, а также обычные команды, чьё имя лишь начинается на префикс (`environment.py`, `timeout_test.sh`). Полный прогон suite зелёный; падение любого существующего теста разбирается как настоящая находка, а не подгоняется.
5. Тест-пин на ОСТАВШУЮСЯ границу: форма, которую этот фикс сознательно НЕ закрывает (например `xargs bash -c` или `ssh host 'cmd'`), закрепляется тестом с комментарием «не исправлено; когда исправят, тест упадёт» — паттерн memory #292.
6. docs/ru/agent-contract.md: «писатель за обёрткой (`sudo tee`)» удалён из списка непойманного, если п.2 его закрывает; остаточная граница переформулирована под фактическое поведение.
7. Все гейты зелёные; полный прогон pytest зелёный.
