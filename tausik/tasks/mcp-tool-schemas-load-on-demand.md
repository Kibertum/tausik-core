## Goal

ЗАМЕР, смена #275: harness/claude/mcp/project/tools*.py объявляют 146 инструментов, суммарно ~22 000 токенов схем, и они пересылаются при КАЖДОМ запросе независимо от задачи. По данным Cursor инструменты, нужные менее чем в 20% разговоров, дают 60% экономии токенов описаний при выгрузке из статики. ПЕРВЫЙ ШАГ — ЗАМЕР, а не правка: по журналу событий посчитать долю смен, зовущих каждый инструмент хоть раз. Ядро остаётся в статике (task start/done/log, verify, status, search, memory add), редкое — имя плюс строка-указатель, полная схема по требованию. У проекта уже есть scope_tools и tools/list с cacheScope=private (решение #394) — это точка, к которой пристраивается выгрузка, а не вторая механика.

## Acceptance Criteria

AC-1 ЗАМЕР ПЕРВЫМ: названа доля смен, зовущих каждый инструмент, числом из журнала. Порог 20% применяется к ЗАМЕРУ, а не к догадке. AC-2 Ядро остаётся в статике и названо списком, объявленным в одном месте. AC-3 Выгруженный инструмент остаётся ВЫЗЫВАЕМЫМ: схема доступна по требованию, путь к ней виден агенту без подсказки человека. AC-4 НЕГАТИВ, главный: инструмент, который модель зовёт на ПЕРВОМ ходу или пытается позвать при отсутствии, из статики НЕ выгружается — иначе экономия оплачивается лишним ходом. AC-5 Замер после: токены схем, доля попаданий в кэш, ошибки вызова инструментов, число ходов на задачу.
