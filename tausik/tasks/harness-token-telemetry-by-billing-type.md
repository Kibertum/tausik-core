## Goal

ЗАМЕР, смена #275: .tausik/token_metrics.jsonl существует, но считает токены ОДНИМ числом. Выход, некэшированный вход и кэшированный вход оплачиваются по разным ценам, и правка, сокращающая запрос но добавляющая ход, может выйти ДОРОЖЕ — измерить это сейчас нечем. Считать надо НА ЗАДАЧУ, а не на запрос: каждый ход пересылает префикс целиком. ЧТО ДЕЛАЕТСЯ: три счётчика вместо одного, доля попаданий в кэш, число ходов на задачу. Источник — поля usage ответа провайдера, а не оценка по символам.

## Acceptance Criteria

AC-1 Метрика различает output, uncached input, cached input тремя числами, снятыми с usage ответа. AC-2 Считается ЦЕНА, а не токены: цены по типу оплаты объявлены в одном месте и названы в отчёте. AC-3 Учёт НА ЗАДАЧУ: доля попаданий в кэш и число ходов привязаны к слагу. AC-4 НЕГАТИВ: отсутствие полей usage даёт ОТСУТСТВИЕ, а не ноль (решение #334) — иначе отчёт покажет бесплатную работу. AC-5 Отчёт называет долю расхода по источнику: схемы инструментов, инструкции, описания навыков, вывод инструментов, история.
