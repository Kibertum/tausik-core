## Goal

Решить axis variants/ (B — две независимые оси: ide + model). Реализовать auto-detect IDE+модели на старте сессии, lazy disk pre-merge skills (нулевой runtime overhead), session state persistence, manual override. Migration существующей плоской variants/<profile>.md в variants/{ide,model}/<slug>.md с backward compat. Без этого B8 (gpt-N variants) — dead code.

## Acceptance Criteria

1. New scripts/skill_profile_detect.py: detect_ide() reads CLAUDE_CODE_*/CURSOR_*/QWEN_*/CODEX_SANDBOX_DIR env vars, returns 'claude'|'cursor'|'qwen'|'codex'|None. detect_model() best-effort returns 'opus'|'sonnet'|'haiku'|'gpt-4'|'gpt-5'|'gpt-5-5'|'qwen'|None from ANTHROPIC_MODEL/OPENAI_MODEL/CLAUDE_CODE_MODEL/QWEN_MODEL env vars. Both pure functions, never raise, no side-effects. 2. New scripts/skill_profile_rebuild.py: rebuild_skills(skills_root, ide, model, force=False) walks all skills under skills_root, computes merged content for each, writes ONLY when sha256(merged) != sha256(existing on disk) — no-op when nothing changed. Returns {rebuilt: [slug,...], skipped: [slug,...]}. Never raises on individual skill errors (skipped with reason in returned dict). 3. Refactor scripts/skill_profile.py: merge_skill_markdown gains explicit (ide=None, model=None) params alongside existing requested_profile (deprecated path kept for backward compat). Two-pass merge: base + variants/ide/<ide>.md + variants/model/<model>.md. Empty/None overlay silently skipped. Backward compat: if variants/ide/ does NOT exist but variants/<slug>.md exists (flat), legacy single-overlay path is used. 4. Migration of harness/skills/{plan,task,ship,_profile-demo}/variants/: existing variants/{sonnet,haiku}.md moved to variants/model/<slug>.md; variants/{claude,codex}.md (in _profile-demo) moved to variants/ide/<slug>.md. Old paths removed. Bootstrap copy logic updated to recursively copy variants/ subtree. 5. Session state file .tausik/.session.json: {ide: str|None, model: str|None, last_rebuild_at: str|null, source: 'env'|'config'|'auto'|'unknown'}. Created/updated by /start. Schema-versioned (schema_version: 1). 6. Override precedence: TAUSIK_MODEL_PROFILE env > TAUSIK_IDE_PROFILE env > .tausik/config.json (model_profile, ide_profile keys) > auto-detect. Resolution function returns (ide, model, source) tuple. 7. New CLI: tausik skill rebuild [--force] — manual trigger, prints rebuilt/skipped counts. tausik config set model_profile <slug> | ide_profile <slug> — persists override into config.json. tausik config show — prints current resolved profile + source. 8. /start skill (harness/skills/start/SKILL.md) Phase 1: invoke detect → resolve precedence → compare with .tausik/.session.json → if mismatch, call rebuild → persist new state. All silent on cache hit. ≤30 lines added to SKILL.md. 9. tests/test_skill_profile_detect.py: ≥10 cases — claude/cursor/qwen/codex detection (env present + missing), model detection per env var, normalize_model_profile_slug for 'gpt-5.5' → 'gpt-5-5', 'GPT-5' → 'gpt-5', case-insensitivity, None when nothing detected. 10. tests/test_skill_profile_rebuild.py: ≥10 cases — rebuild writes when content differs, no-op when sha256 matches (mtime unchanged), force=True always rewrites, missing model overlay skipped silently, missing ide overlay skipped silently, both missing → base only, malformed skill dir handled gracefully (entry in skipped, no exception). 11. tests/test_skill_profile.py: extended with ≥6 new cases for two-axis merge — base+ide+model, base+ide only, base+model only, base only when both unknown, backward compat with flat variants/<slug>.md (no ide/ subdir), priority of ide overlay before model overlay. 12. tests/test_session_state.py: ≥6 cases — schema_version preserved, source field set correctly per precedence path, persist+read roundtrip, missing file returns sane defaults, malformed JSON falls back to defaults (logs warning). 13. Docs: docs/{en,ru}/skill-profiles.md fully rewritten — two-axis variants/ structure (variants/ide/, variants/model/), auto-detect at session start, manual override precedence, CLI commands, migration note for existing skills. 14. CHANGELOG.md + CHANGELOG.ru.md: entry under Unreleased v1.4 polish with rebuild flow + axis decision. 15. Negative scenarios verified: env empty → detect returns None tuple → rebuild uses base only; corrupted .session.json → defaults restored; concurrent rebuild attempts handled (no .lock needed because writes are atomic — file replaced only when content differs). 16. ruff + mypy + pytest + filesize gates green.
