## Goal

НАЙДЕНО ЖИВЬЁМ В #204: гейт заблокировал команду `tausik review record --notes "<длинный русский текст>"`, объявив ВОСЕМЬ целей записи — log, корректная, без, b, только, f, отброшен, out. Все восемь суть слова, стоявшие ПОСЛЕ стрелки «->» в прозе заметок.

ЧТО ПРОВЕРЕНО, А ЧТО НЕТ. Разбор НЕ падал: доверие осталось parsed, то есть аварийный regex-откат ни при чём. shlex с punctuation_chars делит «->» на «-» и «>», а «>» есть полноценный оператор перенаправления, и следующее слово становится его целью. Внутри правильно закрытых кавычек текст остаётся ОДНИМ токеном и беды нет; беда начинается, когда кавычки в прозе теряют баланс и разбор выходит из закавыченного режима. ТОЧНАЯ ПОСЛЕДОВАТЕЛЬНОСТЬ, ЛОМАЮЩАЯ БАЛАНС, НЕ УСТАНОВЛЕНА — установить её ЗАМЕРОМ есть первый шаг задачи, а не догадкой.

ПОЧЕМУ ЭТО ДОРОГО. Запись длинных заметок на русском через CLI — ежедневная операция этого проекта: journal, review record, decide, memory add. Обход есть (текст файлом плюс подстановка, либо текст без угловых скобок), но он найден ценой заблокированной команды и должен быть ЗНАКОМ заранее. Память #507 держит обход; задача держит починку.

КЛАСС ДЕФЕКТА И ГРАНИЦА. Третье семейство ложных блоков гейта записи за две смены: литерал open() из строки или комментария (задача write-gate-reads-open-literals-out-of-strings-and-comments), номер дескриптора (закрыта в #204), и это. Общий корень у всех трёх один — ГЕЙТ РАЗБИРАЕТ ТЕКСТ КАК КОМАНДУ ТАМ, ГДЕ ТЕКСТ КОМАНДОЙ НЕ ЯВЛЯЕТСЯ. Здесь корень конкретнее: аргумент, который заведомо есть ДАННЫЕ, а не команда, разбирается наравне с командой. Отдельной задачей по решению #296: чинится в другом месте и доказывается другими утверждениями.

НАПРАВЛЕНИЕ ОШИБКИ. Ложный блок, то есть пере-обнаружение. Чинить, не открыв дыру: настоящее перенаправление в настоящей команде обязано ловиться по-прежнему, и тесты обязаны это удерживать.

НАЧИНАТЬ С ЦИФРЫ: прогнать write_targets по РЕАЛЬНЫМ длинным аргументам из журнала этого репозитория и предъявить, сколько из них сегодня дают фантомную цель.
