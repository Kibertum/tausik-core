## Goal

Продукт говорит о себе в четырёх местах — README, документация, справка CLI, докстринги — и ни одно из них не связано с кодом, который обязан это исполнять. Следствия все найдены разбором вручную, ни одно проверкой:

README дважды обещает офлайновую проверку квитанции, а документирован только HTTP-сервис, и слово «офлайн» в нём не встречается ни разу. Справка spec add объявляет «закрытый список из 9 типов RENAR» при одиннадцати в стандарте. Справка adapt sign объявляет двойную подпись, отозванную ADR-011. Докстринг is_working_project_db называет функцию защитой, у которой нет ни одного вызова. Докстринг обнаружения корней тестов обещал больше, чем делал код. README обещает ноль обращений наружу при существующей проверке обновления раз в сессию.

Это шесть находок одного класса, и класс называется «сказанное шире сделанного». Гейт запрещённых форм, заведённый задачей outward-text-passes-a-forbidden-forms-gate, проверяет ФОРМУ высказывания и не проверяет ИСТИННОСТЬ.

ЧТО ДЕЛАЕТСЯ: утверждение продукта о себе становится сущностью с ребром на артефакт, который его исполняет. Минимальный объём: только то, что продукт говорит О СЕБЕ наружу — README, справка команд, обещания в докстрингах публичных функций. НЕ весь эпик графа артефактов: подложка берётся из ag-artifacts-and-edges-with-provenance, отдача — только эта.

НЕГАТИВНОЕ: гейт не имеет права требовать ребра от КАЖДОГО предложения документации — это утопит работу в разметке. Предмет проверки есть УТВЕРЖДЕНИЕ О СПОСОБНОСТИ («умеет», «проверяет офлайн», «закрытый список из N»), а не проза. Критерий отбора утверждений называется ДО реализации гейта и проверяется на шести находках выше: гейт обязан покраснеть на каждой из них.
