## Goal

НАЙДЕНО В СЕССИИ #191 ПРИ ЗАКРЫТИИ four-accepted-adrs-were-never-assessed. Та задача исходила из посылки «принятых ADR двенадцать, не оценивались четыре». Посылка проверена машинно по статусам всех 22 файлов корпуса ../../standards/renar/research/decisions/ и НЕ ПОДТВЕРДИЛАСЬ. Фактически: accepted — двенадцать (ADR-001, 003, 005, 006, 007, 009, 012, 013, 020, 021, 022, 023), плюс ADR-011 в состоянии accepted-pending-adr-012 с выполненным условием, то есть принятых ТРИНАДЦАТЬ. Оценено семь: 011, 012, 013 (эпик 1.9) и 020, 021, 022, 023 (закрытая задача). ОСТАЮТСЯ ШЕСТЬ: ADR-001 implements-edge-br-subsystem, ADR-003 ai-agent-as-primary-author, ADR-005 core-concept-overview, ADR-006 adapt-reactive, ADR-007 adapt-temporal-multiplicity-supersession, ADR-009 adversarial-review-record. Поиск по БД по ним даёт НОЛЬ результатов при исправном поиске (контрольные запросы «ADR-020» и «ADR-013» находят задачи, память и решения). Следа оценки нет ни одного. НЕПИСАНАЯ ОЦЕНКА НЕОТЛИЧИМА ОТ ОТСУТСТВУЮЩЕЙ — считать их разобранными «наверное, раньше» есть ровно тот тихий пропуск, против которого заводилась материнская задача. ЦЕНА НЕ ТЕОРЕТИЧЕСКАЯ: ADR-009 adversarial-review-record лежит вплотную к нашему внешнему ревью (SENAR Rule 4, агент tausik-external-reviewer), ADR-006/007 — к ADAPT, у которого в решении #251 уже нашлось отставание от нормы на двойной подписи. ЧТО ДЕЛАЕТСЯ: по каждому из шести — один вердикт из трёх (соответствуем / не соответствуем и чем / не применимо и почему), по той же процедуре, что доказала себя в материнской задаче.

## Acceptance Criteria

AC1. По каждому из шести ADR (001, 003, 005, 006, 007, 009) в журнале стоит РОВНО ОДИН вердикт из трёх: соответствуем / не соответствуем и вот чем / не применимо и вот почему. Шесть вердиктов, ни одного «частично».
AC2. НЕГАТИВНЫЙ СЦЕНАРИЙ, ОБЯЗАТЕЛЕН, ПРОВЕРЯЕТСЯ ПЕРВЫМ. Вердикт «не применимо» без причины, привязанной к НОМЕРУ РАЗДЕЛА и ЦИТАТЕ, найденной в файле ADR МАШИНОЙ, есть провал задачи. Процедура доказала себя в материнской задаче: скрипт сверки цитат, промутированный подмешанной несуществующей цитатой, — зелёный принимается только от проверки, способной покраснеть.
AC3. Утверждение о нашем состоянии подтверждено чтением нашего артефакта, а не памятью: renar/conformance.md, живой gates status, код, БД.
AC4. Долг практики, вскрытый вердиктом, уходит ОТДЕЛЬНОЙ задачей и не поглощается формулировкой «не применимо».
AC5. ADR-009 adversarial-review-record разбирается ПЕРВЫМ и с особым вниманием: у нас есть работающий внешний рецензент (SENAR Rule 4, агент tausik-external-reviewer) и команда review record. Совпадение по духу НЕ ЕСТЬ соответствие — засчитать наш механизм как исполнение ADR-009 можно лишь при совпадении по предмету, доказанном цитатой. Молчаливое «у нас это есть» — провал критерия.
AC6. По завершении в проектной памяти обновлён счёт: принятых тринадцать, оценено тринадцать, непроверенных ноль — либо честно названо, сколько осталось и почему.
