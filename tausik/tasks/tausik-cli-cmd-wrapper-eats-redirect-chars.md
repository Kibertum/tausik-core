## Goal

ЗАМЕРЕНО ЖИВЬЁМ В #200, ТИХАЯ ПОРЧА ДАННЫХ — КЛАСС «НУЛЕВАЯ ТОЛЕРАНТНОСТЬ».
ЧТО ПРОИЗОШЛО. Handoff смены #200 сохранялся вызовом .tausik/tausik.cmd из python через subprocess.run со СПИСКОМ аргументов (то есть без оболочки на стороне python). JSON содержал стрелку из дефиса и знака «больше» внутри текста. Обёртка .cmd передаёт аргументы в cmd.exe так, что знак «больше» ОСТАЁТСЯ УПРАВЛЯЮЩИМ: cmd.exe принял его за перенаправление вывода и создал в КОРНЕ РЕПОЗИТОРИЯ файл с именем следующего слова («dataclass»), куда ушло «Handoff saved for session #200.».
ДВЕ ПОРЧИ, И ОБЕ МОЛЧА. (1) ОБРЕЗАНИЕ: из сохранённого текста пропал кусок от знака «больше» до следующего пробела — «SCHEMA_VERSION 48-» вместо «48->49», «collect_state -» вместо «collect_state -> dataclass фактов». (2) КОДИРОВКА: кириллица в сохранённом JSON пришла с суррогатами U+DC81 и подобными, то есть текст испорчен побайтово. Команда при этом отрапортовала УСПЕХ и вернула ноль. Повреждение обнаружено только сверкой прочитанного handoff глазами.
ПОЧЕМУ ЭТО НЕ «САМ ВИНОВАТ, НЕ ЗОВИ .cmd». Во-первых, .cmd — ШТАТНАЯ точка входа на Windows, её же печатает bootstrap («CLI wrapper: .tausik/tausik.cmd on Windows»). Во-вторых, ровно так её зовёт любой внешний инструмент, у которого нет POSIX-оболочки. В-третьих, отказ обязан быть ГРОМКИМ: команда, которая не может передать свой аргумент дословно, обязана упасть, а не сохранить испорченное и вернуть ноль.
ОБХОД, РАБОТАЮЩИЙ СЕГОДНЯ (записан, чтобы следующий не потерял смену): звать POSIX-обёртку .tausik/tausik из bash и передавать аргумент как "$(cat файл.json)" — так handoff сохранился дословно, суррогатов ноль, проверено grep.
ЧТО ДЕЛАЕТСЯ: (1) экранирование аргументов в .cmd-обёртке так, чтобы знаки «больше», «меньше», «амперсанд», «вертикальная черта», «крышка» и скобки доезжали до python дословно; (2) кодировка UTF-8 на этом пути (кириллица не должна превращаться в суррогаты); (3) САМОПРОВЕРКА: обёртка сверяет, что python получил РОВНО те аргументы, что ей передали, и падает громко при расхождении.
НЕГАТИВНЫЙ СЦЕНАРИЙ ДЛЯ AC: вызов через .cmd с аргументом, содержащим стрелку из дефиса и знака «больше», кириллицу и амперсанд, ОБЯЗАН либо сохранить текст ДОСЛОВНО, либо УПАСТЬ С НЕНУЛЕВЫМ КОДОМ. Молчаливое сохранение обрезанного или перекодированного значения — провал теста. Отдельной проверкой: в рабочем дереве не должно появляться посторонних файлов после вызова (в замере появился файл «dataclass» в корне).
