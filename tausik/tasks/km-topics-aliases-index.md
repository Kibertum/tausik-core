## Goal

Шаг 3 из 6 (решение #143, эпик shared-knowledge). Наивысшая ценность при наименьшем риске — самоценен, даже если шаги 4-6 не делать.

Схема:
- topics(topic_uuid PK, slug, summary <=100 симв., created_at, updated_at, archived_at), где topic_uuid = uuid5(project_ns, нормализованный slug), вычисляется ОДИН раз при создании и никогда не перевыводится из текущего slug (переименование иначе перевыпустит идентичность);
- topic_aliases(slug PK, topic_uuid) — каждый когда-либо использованный slug; переименование ДОБАВЛЯЕТ алиас, старые ссылки резолвятся вечно (паттерн синонимов тегов Stack Overflow и редиректов Wikipedia);
- memory.topic_uuid — nullable, индекс НЕуникальный.

UNIQUE на slug НЕ ставить: он превращает сливаемый дубль в жёсткое нарушение ограничения, а первое переименование становится разрушительной миграцией со сменой PK, рвущей происхождение при слиянии. Уникальность — на topic_uuid. Два разработчика, независимо создавшие verification-discipline, сходятся в один PK без координации, и дубль становится обычным слиянием одной строки.

Инъекция: вместо N последних записей, порезанных посередине слова, — ограниченный индекс строк «slug — summary». Подтверждено независимо: так устроен MEMORY.md самого Claude Code, и retrieval-gated контент измеримо безопаснее прямо загружаемого с точки зрения инъекций в сохранённую память.

Критерий приёмки: инъецируемый блок рендерит не более N строк вида «slug — summary» без обрезков посреди слова, и цифра базового замера (шаг 1) не деградировала.

Негативный сценарий: отсутствие тем у легаси-строк не должно ломать рендер блока — они группируются отдельной строкой с количеством, а не пропадают.

## Acceptance Criteria

1. Инъецируемый блок рендерит не более N строк вида «slug — summary» без обрезков посреди слова.
2. Цифра базового замера (шаг 1) не деградировала после изменения.
3. topic_uuid = uuid5 от нормализованного slug, вычисляется один раз и не перевыводится из текущего slug; переименование ДОБАВЛЯЕТ алиас, старые ссылки резолвятся; UNIQUE на slug отсутствует, уникальность — на topic_uuid.
4. Легаси-строки без темы не ломают рендер — группируются отдельной строкой с количеством, а не пропадают.
