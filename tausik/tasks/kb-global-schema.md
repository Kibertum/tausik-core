## Goal

Новая МАЛЕНЬКАЯ отдельная БД для знаний: память, ключевые решения, сниппеты плюс FTS. Никаких задач, сессий, событий, верификаций — проектная схема сюда НЕ переносится, проектные БД не трогаются вообще. Расположение по умолчанию ~/.tausik/knowledge.db с переопределением через переменную окружения TAUSIK_HOME. Обязательно WAL и busy_timeout: база многописательская ПО ПОСТРОЕНИЮ — у пользователя одновременно открыто несколько IDE и проектов, все полезут в один файл; записей мало, чтений много, для такого профиля WAL оптимален. Длинные транзакции запрещены. Создание базы идемпотентно и ленивое: нет базы — создаём при первой записи, а не при каждом старте.

## Acceptance Criteria

1. Общая база создаётся по пути ~/.tausik/knowledge.db с переопределением через TAUSIK_HOME; тест на переопределение пути проходит.
2. Схема содержит только знания (память, ключевые решения, сниппеты) плюс FTS; задач/сессий/событий/верификаций в ней нет, проектные БД не изменяются.
3. База открывается в режиме WAL с ненулевым busy_timeout; параллельная запись из двух соединений не роняет «database is locked».
4. Создание идемпотентно и ленивое: при отсутствии базы она создаётся при первой записи, а не при каждом старте; повторный старт нового файла не порождает.
CHANGELOG.md [Unreleased] и зеркало CHANGELOG.ru.md обновлены прозаической записью об этом изменении.
