## Goal

Не давать ЛЮБОМУ агенту (Claude/Cursor/Copilot/Windsurf/aider/ручная правка) уводить project-знания в свою память мимо TAUSIK. 3 слоя, один deny-list (single source of truth, bootstrap-зеркалит во все адаптеры — дисциплина #146): (1) УНИВЕРСАЛЬНЫЙ: gate 'memory_route' + git pre-commit hook (IDE-агностичны) — fail-closed если в working tree попал файл из deny-list чужих memory-стоков (~/.claude/**/memory, .cursor/rules, .cursorrules, .windsurf/**, .github/copilot-*, .aider*); (2) БЫСТРЫЙ per-harness: Claude PreToolUse-хук memory_route_gate (как task_gate), для Cursor — когда появится механизм; (3) ИНСТРУКЦИЯ для не-файловой/облачной памяти: единый литмус-блок 'project knowledge → tausik memory add' в bootstrap-шаблонах AGENTS.md/CLAUDE.md/.cursorrules. Честное ограничение: чисто облачную память без файла на диске ловит только слой 3.

## Acceptance Criteria

1. Единый deny-list модуль (foreign memory sinks) — один источник, потребляется всеми слоями. 2. gate 'memory_route' (в gates_status, fail-closed severity): сканит working tree, блокирует если есть файл из deny-list. 3. git pre-commit hook вызывает gate → коммит, трогающий чужой memory-сток, отклоняется с редиректом на 'tausik memory add'. 4. Claude PreToolUse-хук memory_route_gate блокирует Write/Edit/Bash-append по deny-list путям (ловит и Edit, и Bash). 5. Литмус-блок добавлен в bootstrap-шаблоны AGENTS.md/CLAUDE.md/.cursorrules, синкается bootstrap. 6. NEGATIVE: 'tausik memory add' и легитимные файлы проходят без блока; запись в ~/.claude/**/memory или .cursorrules → блок с сообщением-редиректом. 7. Тесты на deny-list матчинг, gate, hook (positive+negative). 8. Все гейты зелёные.
CHANGELOG.md [Unreleased] и зеркало CHANGELOG.ru.md обновлены прозаической записью об этом изменении.

## Rollback

git revert коммита. Гейт независимо выключается через .tausik/config.json -> gates.memory_route.enabled=false (его читают и гейт-раннер, и pre-commit — один переключатель, не два). Хук отключается TAUSIK_SKIP_MEMORY_HOOK=1 (пишет bypass-событие). Ни одна из трёх точек не требует отката остальных.
