## Goal

Замер, сессия #178: TOOLS сервера tausik-project содержит 117 определений, json.dumps даёт 44501 байт. Протокол MCP пересылает имя и схему КАЖДОГО инструмента на каждом ходу, если клиент не умеет откладывать схемы. Порядок величины — около одиннадцати тысяч токенов на ход только на описание поверхности, до единого полезного вызова. Claude Code этот удар смягчает отложенной загрузкой схем, но это свойство КЛИЕНТА, а не наша заслуга: у Cursor и Qwen такой защиты нет, и там счёт платится целиком. Задача: назвать цену числом в документации, а затем сократить её — разделением поверхности по областям, объединением команд одного семейства или отказом от инструментов, которые дублируют CLI без выигрыша. Смежное ограничение уже заведено задачей mcp-tools-list-caching-conflicts-with-scope-hiding: кэшируемый tools/list против скрытия по scope — решать вместе, иначе сокращение поверхности покажет клиенту то, чего уже нет.

## Acceptance Criteria

ЗАМЕР СМЕНЫ #229 ОБНОВИЛ ЧИСЛА ПОСТАНОВКИ И ПОКАЗАЛ, ЧТО ОНИ ДВИГАЛИСЬ В ОБРАТНУЮ СТОРОНУ: не 117 инструментов и 44 501 байт (замер #178), а 145 и 56 108 байт — поверхность выросла на 24% и 26%, и никто этого не заметил, потому что число жило в тексте задачи.

AC1. ЦЕНА НАЗВАНА ХРАПОВИКОМ, А НЕ ТЕКСТОМ. Число, записанное в документ, уже сгнило один раз ровно этим способом. Появляется baseline поверхности MCP в tausik/gates.json по образцу class_surface: РАЗРЕШЕНО УМЕНЬШАТЬСЯ, запрещено расти. Гейт считает и число инструментов, и байты сериализованного описания, и краснеет при превышении baseline. Тест утверждает, что гейт краснеет на выдуманном превышении, а не только зеленеет на текущем состоянии.

AC2. ЦЕНА НАЗВАНА ПО ХОСТАМ, А НЕ ОДНИМ ЧИСЛОМ. Замер: полная поверхность 56 108 байт (~14 027 токенов), только имена — 3 201 байт (~800 токенов), отношение 17.5. Claude Code откладывает схемы и платит имена; хост без отложенной загрузки платит всё. Обе величины названы, и сказано, какая из них НАБЛЮДАЛАСЬ здесь, а какая выведена из протокола — второе обещание релиза про любую модель, и разница в 17.5 раза между хостами есть факт этого обещания.

AC3. МЁРТВЫХ ИНСТРУМЕНТОВ НЕТ, И ЭТО ИЗМЕРЕНО, А НЕ ПРЕДПОЛОЖЕНО. Сверка объявленных имён с таблицей диспетчеризации: 145 против 145, разность в обе стороны пуста. Значит свободного сокращения (удалить неработающее) НЕ СУЩЕСТВУЕТ, и любое сокращение поверхности есть продуктовое решение об отказе от живой возможности. Тест закрепляет РАВЕНСТВО множеств: инструмент без обработчика и обработчик без объявления одинаково запрещены.

AC4 (НЕГАТИВНЫЙ СЦЕНАРИЙ). Храповик, который никогда не краснел, доказательством не является. Проверяется: baseline, уменьшенный на единицу, даёт КРАСНЫЙ гейт с внятным сообщением, называющим и текущую величину, и baseline; отсутствие ключа в gates.json НЕ отключает проверку молча, а даёт явный отказ или явное значение по умолчанию; нечитаемый gates.json не роняет прогон.

AC5. СОКРАЩЕНИЕ НЕ ДЕЛАЕТСЯ ЗДЕСЬ, И ПРИЧИНА НАЗВАНА. Уменьшение поверхности означает отказ от живых инструментов, слияние семейств (task 22, actz 15, memory 14) или разделение сервера по областям — всё это меняет контракт для потребителей и связано ограничением задачи mcp-tools-list-caching-conflicts-with-scope-hiding (кэшируемый tools/list против скрытия по scope). Решение об этом записывается как вопрос владельцу, а не принимается молча внутри задачи о ЦЕНЕ. Обещание экономии от сокращения поверхности НЕ публикуется, пока сокращения нет.
