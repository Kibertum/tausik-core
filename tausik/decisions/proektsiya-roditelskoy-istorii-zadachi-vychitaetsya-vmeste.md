## Decision

ПРОЕКЦИЯ РОДИТЕЛЬСКОЙ ИСТОРИИ ЗАДАЧИ ВЫЧИТАЕТСЯ ВМЕСТЕ С ЕЁ СОБСТВЕННЫМ ЭКСПОРТОМ; ЭПИК — НЕТ. Множество бухгалтерии задачи получает второго члена: tausik/stories/<родитель>.md. Слаг родителя читается из собственного экспорта задачи парсером state_parse, а не запросом к БД. Чужая история остаётся недекларированной.

## Rationale

Кандидатов было три. (б) Вычитать любой файл проекции, чью правку сделал фреймворк — формулировка честнее, но неисполнима: несохранённое изменение не несёт автора, ручная правка внутри проекции побайтово совпадает с записью экспортёра; эту границу verify_own_export уже объявил для --no-file-changes. (в) Не вычитать вовсе — возвращает бесполезность, снятую #283: значение, одинаковое почти у всех. Выбран (а) — узкое вычитание родителя ТЕКУЩЕЙ задачи: файл изменился потому, что задачу активировали, и изменился бы так же, не сделай агент ничего. Граница #283 цела: чужая история есть продукт задачи, которая её правит. ЭПИК НЕ ВЫЧИТАЕТСЯ ПО ЗАМЕРУ: за #196 (два task start, task done, task add, task move) git ни разу не показал изменения проекции эпика. Источник слага — экспорт, а не conn: вызывающие соединения не держат, а оба вида устаревания проекции безопасны.
