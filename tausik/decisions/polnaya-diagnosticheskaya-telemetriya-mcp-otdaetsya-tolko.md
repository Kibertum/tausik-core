## Decision

Полная диагностическая телеметрия MCP отдаётся только по ЯВНОМУ вызову (tausik_self_check), но НЕ в автоматическом конверте /start (session_open).

## Rationale

Различие не в объёме, а в согласии. /start отрабатывает без участия человека каждую сессию, поэтому всё, что лежит в его конверте, — постоянная автоматическая выгрузка в транскрипт LLM-провайдера. watched_modules + current_mtimes публиковали 108 абсолютных путей рабочего дерева разработчика (структура каталогов вместе с именами заказчиков: [вычеркнуто: local-path]<заказчик>\...) плюс mtime-отпечаток машины. Ни одно из этих полей дашборд не рендерит — цена ненулевая, польза нулевая. Разделение: неявный, автоматический путь минимален по умолчанию; полная телеметрия остаётся в шаге одного явного вызова, где агент/пользователь осознанно её запрашивает под конкретную диагностику. Следствие для stale_modules: при дрейфе достаточно basename (ремедиация — «перезапусти IDE»), абсолютный путь остаётся в tausik_self_check. Обобщение: для каждого поля автоматического ответа спрашивать не «полезно ли оно», а «оправдывает ли польза ПОСТОЯННУЮ выгрузку без спроса».
