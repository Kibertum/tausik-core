## Decision

Gate B закрывается БЕЗ количественного вердикта: прибора для поатрибутной стоимости инструментов не существует, поэтому решение о саб-агентах принимается на качественных основаниях. Вывод `tausik metrics tokens` обязан перестать утверждать атрибуцию, которой не делает.

## Rationale

Замер, а не мнение. (1) Пре-саб-агентного среза нет: агенты приземлились 2026-04-10..17, телеметрия начинается 2026-06-15, baseline.json отсутствует (решение #197). (2) Хуже: прибор не меряет ожидаемое. scripts/hooks/token_metrics.py сам помечен deprecated со словами «PostToolUse payload carried per-tool API usage. It does not — usage is message-level». Данные подтверждают: input_tokens равен 2 у 7116 строк из 8046, in_p50 и in_p90 равны 2 У КАЖДОГО инструмента, а input_tokens_total, по которому таблица СОРТИРУЕТСЯ, есть просто 2*events — счётчик вызовов под видом стоимости. Сумма cache_read даёт 568 млн для Bash за 26 сессий: один кэш пересчитан на каждом вызове. Вызовы Agent записаны как 2 токена, расход саб-агента невидим. Отвергнуто: считать долю по этим полям (красивое число ни о чём); строить новый пайплайн телеметрии сейчас (отдельная работа, релиз от неё не зависит).
