## Decision

## Rationale

ИСТОЧНИКИ (#189): Anthropic «Effective context engineering» и «Managed Agents»; 12-factor agents (факторы 5/6/8/12); LangGraph (чекпойнт на каждом шаге, ветвление от прошлого); Letta (правимые агентом блоки памяти); практика Claude Code «новая задача — новый контекст».
ТРИ СЛОЯ ВМЕСТО ОДНОГО ПОНЯТИЯ: журнал — единственный источник истины, прочее есть его проекция (фактор 5); контекст — политика харнесса (ядро памяти всегда в окне, архив по релевантности, инструктированная компакция, стабильный префикс под кэш); единица работы — ЗАДАЧА: один журнал, одно окно, один коммит.
ОТВЕРГНУТО: отказаться от сессий (ни одна разобранная система этого не делает, все держат долговечный журнал); оставить сессию-день (длинна для окна, коротка для непрерывности); генератор вводного промпта (лечит симптом: промпт нужен из-за отсутствия ядра); пол отсчёта на начале сессии, вариант потребителя (якорь обязан быть git-коммитом).
ПРИЁМКА — учение с холодным стартом, ДО и ПОСЛЕ. ПОРЯДОК: сначала CI на ветке.
