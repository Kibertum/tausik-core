## Decision

Ревью-агентам с правом RUN/reproduce не давать живое рабочее дерево — только изолированную копию (snapshot в temp) с явным разрешением ломать её. Worktree-изоляция для НЕЗАКОММИЧЕННОЙ работы не подходит: worktree создаётся из коммита, агенты увидят HEAD, а не твою дельту.

## Rationale

Инцидент сессии #111. Ревью запущено с формулировками «RUN things», «reproduce», «construct the exact broken input». У tausik-reviewer и workflow-агентов есть Bash. Пять агентов параллельно ломали строки в ЖИВОМ bootstrap.py и возвращали назад — пока я в том же файле правил код и гонял тесты.

Симптомы принял за мистику: файл «сам» откатился до HEAD/v1.6.1 с потерей ВСЕЙ ветки OpenCode; git status мигал чистый/грязный; размер скакал 13935 vs 13522; integrity-проверка падала, а через секунду grep говорил «всё на месте» — едва не списал её на ложную тревогу, хотя она была права в тот момент. Один агент не успел откатить: релиз чуть не ушёл без целой фичи, поймал случайно.

ХУЖЕ САМОЙ ПОРЧИ: прогоны тестов, шедшие ОДНОВРЕМЕННО с ревью, недостоверны — дерево менялось под ними, зелёный цвет ничего не доказывал. Пришлось перегонять на тихом дереве (4716 FULL / 4583 FAST — первый достоверный).

Решение проверено: cp -r bootstrap scripts tests harness docs + корневые .md/.toml в temp (7.4 МБ, без .git/venv/__pycache__), ревью против копии. 78 агентов, ноль касаний рабочего дерева, чистый вердикт SHIP.
