## Decision

ПРОВЕРКА ОБНОВЛЕНИЯ С GITHUB ОБЯЗАТЕЛЬНА В 1.10. Владелец, смена #264, после того как выяснилось, что уведомлятора об обновлении нет и не было в 1.8 (единственное обращение наружу в продукте — push-ok читает статус CI, и оно — акт владельца). Источник — GitHub (Kibertum/tausik-core): потребитель на N узнаёт о выходе N+1 не позже старта следующей смены, с номерами обеих версий и ссылкой на релиз. Следствие, принимаемое вместе с этим: фраза README «0 обращений наружу / 0 phone-home calls» перестаёт быть правдой и переписывается в том же изменении до фактического механизма — что уходит, куда, как часто, как выключить. Открытым остаётся один выбор, который делается в задаче измерением: механизм (git ls-remote по тегам / REST releases/latest / remote сабмодуля) и умолчание (включено с opt-out или opt-in). Задача session-update-check-collides-with-the-zero-phone-home-claim, история 1.10.

## Rationale

Пользователь 1.8 сегодня узнаёт о 1.9 только зайдя на GitHub; фреймворк, который не умеет сказать «есть новее», оставляет каждого потребителя на первой установленной версии.
