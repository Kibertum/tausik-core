## Rationale

Замер сессии #180: GitHub main это 13 коммитов по одному на релиз, GitLab main 405, общего предка НЕТ, и публичное дерево есть внутреннее МИНУС вся проекция tausik/ (2233 файла, 67194 строки, ноль удалений в другую сторону). Скан на секреты чист. Утекают четыре вещи: [вычеркнуто: internal-host] (17 файлов), имена чужих проектов [вычеркнуто: third-party-project]/[вычеркнуто: third-party-project]/[вычеркнуто: third-party-project]/YPN/cyrm (44 файла), локальные пути с именем пользователя (12), масштаб раскатки на 30 репозиториев. Переписывание истории отвергнуто по трём измеренным причинам: строки живут в БАЗЕ и регенерируются в проекцию первым же task log, поэтому чистка одного git бесполезна; строки есть в сообщениях девяти коммитов; filter-repo меняет все SHA, а README велит подключать github.com/Kibertum/tausik-core сабмодулем — пины потребителей, внешний PR #5 и 22 тега ломаются. Чистый лист покупает отсутствие переписывания, целые пины и отказ от вычистки восьми месяцев журналов.
