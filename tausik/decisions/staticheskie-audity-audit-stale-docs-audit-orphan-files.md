## Decision

Статические аудиты (audit_stale_docs, audit_orphan_files, audit_unused_python) обходят git-индекс, а не файловую систему. Единый хелпер scripts/audit_tracked_files.py на git ls-files; при недоступности git — None и деградация до обхода ФС с предупреждением в stderr.

## Rationale

Все три аудита ходили rglob-ом по ФС, при том что их собственные докстринги обещали отчёт по отслеживаемым файлам — реализация расходилась с задекларированным контрактом. Следствия измерены: 3 кандидата из 3 ложные, причём gitignored файл по определению ни из чего не ссылается и «починить» его нельзя (вечный шум), а его имя печаталось в отчёт вопреки конвенции #176 о неразглашении внутренних исследований. Выбран обход индекса, а не парсинг .gitignore: git — единственный источник правды об отслеживаемости, парсер .gitignore пришлось бы поддерживать и он всё равно врал бы на явно добавленных файлах. Симметричное лечение всех трёх, а не только заявленного в задаче, потому что болезнь структурная. Регрессия проверена сравнением вывода базовой и новой версии соседних аудитов — оба были и остались пустыми.
