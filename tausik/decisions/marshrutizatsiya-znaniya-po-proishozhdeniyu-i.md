## Rationale

РЕШЕНИЕ ВЛАДЕЛЬЦА 29.08. ПРИЗНАК — ПРОИСХОЖДЕНИЕ: узнал из файлов ЭТОГО репозитория -> проектная память; из поведения инструмента или платформы (Windows, pytest, Ansible, git, модель) -> общая база; от пользователя -> авто-память агента. ДВИЖЕНИЕ — АВТОМАТИЧЕСКОЕ по признаку, а не по явной команде.
ПОЧЕМУ ПАРА СОГЛАСОВАНА, А МОЯ РЕКОМЕНДАЦИЯ БЫЛА ХУЖЕ: автоматика требует МАШИННО НАБЛЮДАЕМОГО признака. Происхождение наблюдаемо — чем порождена запись: чтением файла, выводом инструмента, репликой пользователя. «Что сделает утверждение ложным» есть суждение, машиной не применимое.
ГРАНИЦА, СОХРАНЯЮЩАЯ #221: автоматика работает ТОЛЬКО между тремя ЛОКАЛЬНЫМИ адресами. Brain — публикация наружу — остаётся явным действием.
УСЛОВИЕ: общая база не редактируется (secrets и PII хранятся дословно, читаются из всех проектов), значит автозапись обязана проходить redact-проверку — команда есть с 1.9. Иначе гоча с токеном становится утечкой на всю машину.
