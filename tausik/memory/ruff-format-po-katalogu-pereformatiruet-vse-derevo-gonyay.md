ЗАМЕР. `python -m ruff format scripts/ tests/ harness/` в смене #201 переформатировал 96 файлов, из которых 92 не имели к задаче никакого отношения. Дерево мгновенно перестало соответствовать ACL задачи, а diff стал нечитаемым.

ПРИЧИНА, ПОЧЕМУ ЭТО НЕ ОЧЕВИДНО ЗАРАНЕЕ. Лента зелёная, гейт ruff check зелёный, mypy зелёный — то есть НИ ОДИН контроль не краснеет от того, что ты переформатировал полрепозитория. Обнаруживается только глазами в git status, и только если посмотреть. В проекте, где формат не прогоняется по всему дереву регулярно, накопленная разница велика, и одна команда её всю материализует.

ПРАВИЛО. `ruff format` вызывать ТОЛЬКО со списком файлов задачи, никогда с каталогом. `ruff check` по каталогу безопасен — он читает, а не пишет.

ЕСЛИ УЖЕ СЛУЧИЛОСЬ: список к откату собирается из git status минусом файлов scope, откат через `xargs git checkout --`. НЕ трогай `git stash` в этот момент: stash уносит и твои правки тоже (проверено в той же смене — пришлось делать stash pop и повторять отбор).
