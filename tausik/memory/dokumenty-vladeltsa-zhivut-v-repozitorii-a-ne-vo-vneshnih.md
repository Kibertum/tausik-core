Требование владельца, сессия #178: не создавать внешние артефакты для документов проекта. Планы, отчёты, заметки к выпуску и обзоры сохранять файлами В РЕПОЗИТОРИИ.

ПОЧЕМУ ЭТО НЕ ВКУСОВЩИНА: документ вне репозитория не проходит гейты, не попадает в диф, не версионируется вместе с кодом, который описывает, и не может быть предъявлен вместе с квитанцией. Для проекта, который продаёт привязку доказательства к состоянию кода, документ, живущий отдельно от кода, есть ровно то, что этот проект запрещает.

КУДА КЛАСТЬ: корень репозитория по образцу существующих — TAUSIK-report-survey.pdf, TAUSIK-report-uniqueness-survey.md, TAUSIK-roadmap.pdf. То есть TAUSIK-<предмет>.<расширение>. Исследовательские заметки — docs/ru/research/ с зеркалом в docs/en/research/. Заметки к выпуску — docs/{ru,en}/whats-new-<версия>.md, откуда собирается текст тега.

СЛЕДСТВИЕ ДЛЯ ОБЛАСТИ ЗАПИСИ: шаблон TAUSIK-*.md уже входит в область записи задач обзора, поэтому запись такого файла не требует расширения ACL.
