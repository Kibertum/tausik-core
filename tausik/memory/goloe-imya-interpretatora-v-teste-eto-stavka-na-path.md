Замер #206. Пять тестов звали subprocess.run(['bash', './probe.sh']). На windows-latest первым в PATH стоит System32\bash.exe - пусковая заглушка WSL, и без дистрибутива она даёт rc=1 и текст в UTF-16. Три полосы Windows краснели ДЕВЯТЬ дней, ubuntu и macos были зелёные. Продукт был исправен - ошибалось ожидание теста о среде. Лечение: не список путей, а ПРОБА в той форме, какой пользуются вызывающие (файл скрипта из рабочего каталога); заглушка не проходит её по построению, узнавать её по имени не нужно. ВАЖНО про воспроизведение: машина с установленным дистрибутивом WSL условие CI НЕ воспроизводит - там заглушка пробу проходит и решает только порядок кандидатов. Значит заглушку в тесте надо СТРОИТЬ.
