Запись, которая говорит 'X удалён', не может перестать называть X — поэтому всякое правильное удаление заново открывало регистр протухших ссылок. Шестнадцать находок смены #277 — ровно этот случай: утверждение верно, файл исчез намеренно.

ФОРМА: путь, за ним в скобках хеш коммита — 'bootstrap/generator.py (удалён в a6f614a2)'. Проза допускается с обеих сторон хеша внутри скобок; сам хеш обязателен, и проверяется только его ФОРМА (7-40 hex), никогда git cat-file: спросить git значит позволить сломанному git молча выключить детектор. Голое '(удалён)' не проходит — утверждение об удалении стоит того коммита, который читатель может открыть.

СЛЕДСТВИЕ ДЛЯ ЖУРНАЛА: не цитируй протухший путь целиком в тексте, объясняющем детектор, — иначе запись сама становится находкой. Проверено трижды за смену, включая правку записи о различении tausik/ и точка-tausik, которая с первой попытки воспроизвела неверное имя.
