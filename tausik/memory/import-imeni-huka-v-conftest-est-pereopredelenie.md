Смена #239. Вписал в tests/conftest.py 'from red_history_plugin import pytest_runtest_logreport, pytest_sessionfinish'. Оба имени в файле УЖЕ БЫЛИ: первое копило длительности для сторожа зависаний, второе превращало превышение в ненулевой код выхода. Импорт молча заменил бы оба — обмен двух работающих механизмов на один новый, незамеченный.

ПОЙМАЛ ТОЛЬКО RUFF (F811, redefined). Тесты сторожа зависаний зелены и без него: превышения в обычном прогоне нет, поэтому пропажа механизма ничего не красит. Это класс дефекта, который переживает полный прогон.

ПОЧЕМУ ЛЕГКО ПОПАСТЬСЯ: conftest на 570 строк с десятком хуков, и глазом дубликат не виден. А импорт выглядит как «подключаю», хотя по семантике Python это присваивание имени в модуле.

КАК ПРАВИЛЬНО: существующий хук ЗОВЁТ функцию плагина явно. Все механизмы остаются, вызов виден там же, где определён хук. Регистрация через pytest_plugins в conftest вне корня в pytest 7+ даёт ошибку, а -p в addopts трогает pyproject.
