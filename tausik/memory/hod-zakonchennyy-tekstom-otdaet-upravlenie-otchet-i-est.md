Замер смены #277 по транскрипту: 4507 ходов с вызовами инструментов против 78 сообщений владельца — то есть примерно на каждое сообщение владельца приходился один мой финальный отчёт, и каждый из них останавливал работу. Продолжить самостоятельно агент не может, только владелец. Отсюда правило: текст в чат ТОЛЬКО когда работа по указанию кончилась или нужно решение владельца; ход работы, замеры и находки — в journal задачи. Проверяется вопросом перед каждым текстом: «просили ли меня решить, или я просто закончил шаг?». Ожидание фонового прогона — не повод: в это время делается подготовка, не трогающая дерево.
