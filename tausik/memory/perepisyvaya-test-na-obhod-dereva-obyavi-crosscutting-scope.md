Резолвер сопоставляет тест с изменением ПО ИМПОРТАМ. Тест, который вместо импорта продуктового кода начинает ОБХОДИТЬ ДЕРЕВО (os.walk, glob, rglob по scripts/harness/bootstrap/docs), теряет эту связь: ни одно изменение больше не выбирает его в scoped-прогоне, и он выполняется только в полной ленте.

ЗАМЕР (#211): переписал tests/test_no_hard_yaml_import.py с напечатанного списка модулей на обход деревьев. Все scoped-прогоны остались зелёными, а ПОЛНАЯ ЛЕНТА дала 1 failed — test_crosscutting_registry поймал файл как сквозной без объявления. То есть цену переписывания предъявила машина, а не автор.

ПОРЯДОК: сделав тест сквозным, объяви CROSSCUTTING_SCOPE = ['scripts/', ...] ЛИТЕРАЛОМ (см. соседнюю память про литералы), либо CROSSCUTTING_SCOPE = [] как видимый отказ. Затем проверь ХРАПОВИК: если файл числился в _INVISIBLE_BASELINE, объявление обязано вывести его оттуда, и test_invisible_baseline_only_shrinks потребует сокращения базового списка. Оба шага — не бюрократия: без первого тест не выбирается ничем, без второго он числится объявленным и невидимым одновременно.

И ПРОГОН: такие поломки НЕ ВИДНЫ scoped-прогону по определению. Полная лента после переписывания сквозного теста обязательна.
