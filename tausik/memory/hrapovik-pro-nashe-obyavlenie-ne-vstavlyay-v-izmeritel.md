Сравнение живого множества с зафиксированным свидетелем корректно только для той базы, о которой объявление сделано. Вписанный в клаузу манифеста, такой храповик объявил «появился класс» для КАЖДОЙ фикстуры — включая ту, что заводит таблицы DDL-ом намеренно, потому что продовая схема их держать не может. Восемь красных тестов. Красное по причине, не связанной с проверяемой защитой, есть тот же дефект, что и зелёное по такой причине. Признак к распознаванию: измеритель сравнивает с ЗАФИКСИРОВАННЫМ состоянием, а вызывается там, где база приходит аргументом. Лечение — разделить: храповик отдельной функцией с единственным потребителем на живой базе, публикуемое значение только на фактах поданной базы.
