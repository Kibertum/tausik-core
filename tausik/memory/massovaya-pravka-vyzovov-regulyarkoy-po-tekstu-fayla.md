Approach: Массовая правка вызовов регуляркой по тексту файла
Reason: Дала два дефекта: open(path,'rb').read() стал read_text() — двоичное чтение превратилось в декодированную строку, sha256 считался бы по тексту; и правка read_text() внутри строкового ЛИТЕРАЛА фикстуры сломала кавычки. Текстовая замена не различает код от данных и молча теряет позиционные аргументы. Следующий раз — по AST либо с проверкой каждого отброшенного аргумента по диффу.
