Переписывая 111 вызовов open(...).read() на Path.read_text, скрипт отбрасывал позиционный режим. Три случая с 'w' вышли верными — write_text усекает так же. Четвёртый был open(path, 'rb').read(): двоичное чтение стало ДЕКОДИРОВАННОЙ строкой, и sha256 считался бы по тексту вместо байтов.

ЛЕНТА ПОЙМАЛА ЭТО СЛУЧАЙНО — на тесте, который читает манифест и падает UnicodeDecodeError на cp1252. Если бы файл оказался ASCII, тест прошёл бы, а хеш был бы другим по существу.

ПРИЁМ: после массовой правки пройти по ДИФФУ и найти каждый вызов, у которого исчез позиционный аргумент; для каждого ответить, изменилось ли поведение. Проверка занимает один проход по diff и находит то, чего лента не обязана находить: отброшенный режим меняет СМЫСЛ, а не форму, и тест на это может просто не существовать.
