Утверждение assert exc.value.code == EXIT_MANGLED проходит при ЛЮБОМ значении константы, включая ноль. Мутация EXIT_MANGLED = 3 -> 0 в #209 ВЫЖИЛА при 34 зелёных тестах: страж переставал быть громким, а лента этого не замечала. Правило: код выхода утверждай литералом (assert code == 3), а связь литерала с константой — отдельной строкой (assert EXIT_MANGLED == 3), плюс утверждение о СВОЙСТВЕ (не ноль и не 2, потому что 0 вернёт молчание, а 2 читается как ошибка употребления команды). Обобщение: тавтологичен любой тест, где ожидаемое значение взято из того же места, что и проверяемое; такую тавтологию ловят только мутации, не покрытие.
