Чтобы доказать, что новый тест умеет краснеть, файл временно ломают в no-op. Откат мутации через `git checkout -- <file>` возвращает файл к HEAD, а НЕ к состоянию до мутации — вся незакоммиченная работа задачи в этом файле исчезает молча, и `git diff --stat` показывает пустоту, что легко прочитать как «успешно откатил».

В сессии #115 так были снесены все правки audit_stale_docs.py (28 вставок). Спасла копия, снятая до мутации: `cp file /tmp/f.bak` в начале той же составной команды, восстановление `cp /tmp/f.bak file`.

Правило: мутируешь файл с незакоммиченными правками — откатывай ТОЛЬКО из копии, снятой перед мутацией, и проверяй восстановление диффстатом (должен совпасть с домутационным) плюс прогоном тестов. `git checkout`/`git restore` применимы лишь к файлу, чьи правки уже в HEAD.

Проверка бэкапа перед восстановлением обязательна: он не должен содержать маркер мутации.</content>
