Утверждение вида assert manifest["replaced-by"] == UNKNOWN_STATE_SENTINEL ПЕРЕЖИВАЕТ любое изменение константы: обе стороны сравнения берутся из одного источника. Тест зелёный, а проверяемого свойства нет. Поймано мутацией M2 в задаче о снятии заявки RENAR-1: подмена sentinel на "null" НЕ уронила тест, хотя дефект был грубый.
ПРАВИЛО: если значение предписано ВНЕШНЕЙ нормой (статья стандарта, протокол, формат чужого API), тест обязан называть ЛИТЕРАЛ этой нормы, а не импортировать константу кода. Константу проверяй ОТДЕЛЬНОЙ строкой: assert UNKNOWN_STATE_SENTINEL == "<unknown-state>". Тогда мутация константы падает, и падает именно там, где норма нарушена.
ГДЕ ЭТО НЕ ТАК: если значение — внутренняя деталь без внешнего предписания, импорт константы правилен, потому что нормы, которую можно процитировать, не существует.
ЦЕНА ОБНАРУЖЕНИЯ: одна мутация. Без неё дыра уехала бы в закрытую задачу с зелёным чек-листом.
