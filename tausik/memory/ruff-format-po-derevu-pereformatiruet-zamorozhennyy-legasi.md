Второй раз за смену. У проекта есть храповик ruff_format с замороженным списком файлов, которые НЕ форматируются: список может только сокращаться. Команда ruff format tests/ scripts/ переформатировала 113 файлов, из них 97 из списка — и это не улучшение, а чужой шум в диффе задачи плюс красный храповик.

ПРИЁМ: форматировать ПОИМЁННО те файлы, которые правил. Если дерево уже переформатировано — разделить диффы: файл, в добавленных строках которого есть след моей правки, оставить; остальные вернуть через git checkout. Проверка на след дешевле, чем разбор построчно.

ВТОРАЯ ПОЛОВИНА: файл из списка, который я правил и который теперь отформатирован, ОБЯЗАН уйти из списка — храповик именно этого и требует. Не откатывать его формат, а сократить список.
