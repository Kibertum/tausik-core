Чистая выгрузка через git worktree --detach даёт ровно условие CI: нет ни .tausik/, ни .claude/, оба в .gitignore. Переименование базы на рабочей машине этого НЕ даёт и ломает собственные хуки агента. В #203 worktree показал то, чего не дал бы статический разбор: bootstrap базу не создаёт, зато САМА ЛЕНТА создаёт её по ходу прогона, отчего гейтящиеся на базе контроли выполняются или нет в зависимости от порядка. Мутации для таких контролей прогоняй В worktree: мутация, убитая на машине разработчика, доказывает ровно то, что задача и устраняет.
