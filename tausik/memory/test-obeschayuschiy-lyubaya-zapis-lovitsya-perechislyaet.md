review-207-open-spy-blind-and-doctor-at-cap (#207): страж таблицы мутаций патчил builtins.open и io.open и обещал в докстринге, что любая запись вне tmp_path будет поймана; два из шести билдеров писали через sqlite3.connect и subprocess git — невидимо для спая. Ревью воспроизвело пробником (written == [] при созданном файле БД). Правило: у стража, чьё обещание «всё», инвентарь каналов снимается по ВЫЗОВАМ охраняемого кода (память #527), каждый канал патчится, и тест утверждает, что канал сработал, — иначе билдер может тихо перейти на неотслеживаемый канал, и страж останется зелёным по неверной причине. Что не перехватывается (os.open, прямые syscalls, действия дочернего процесса) — называть в докстринге.
