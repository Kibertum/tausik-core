Два разных вопроса о пути требуют двух разных инструментов, и их путают.

«Тот ли это самый каталог?» — вопрос о ТОЖДЕСТВЕ. Отвечает `os.path.normcase(os.path.realpath(p))`. Сравнение строк здесь ошибочно: один каталог имеет много законных написаний. На Windows подъём приходит от `TMP`, записанного коротким именем 8.3 — `C:\Users\[вычеркнуто: local-path]\.tausik`, — а `expanduser` отдаёт длинное `C:\Users\[вычеркнуто: local-path]`. Написания разные, каталог один. Первая версия запрета на пользовательский тир сравнивала строки и дефект пережила целиком.

«Как записан этот путь?» — вопрос о ФОРМЕ. Отвечает чтение самой строки (конвенция #378: предикат о форме пути читает написание, а не спрашивает платформу). `realpath` здесь ошибочен: он уничтожает ровно то, о чём спрашивают, — например превращает UNC в нечто иное вне Windows.

Как отличить: если ответ должен совпасть для двух разных записей одного объекта — тождество, `realpath`. Если ответ должен различаться для двух записей одного объекта — форма, строка.

Симптомы неверного выбора: проверка работает на машине автора и не работает под pytest либо в подпроцессе; условие «никогда не выполняется» или «выполняется всегда» без видимой причины.
