В #205 я дважды чинил резолв относительных путей по полю cwd события и дважды проверял только «где стоит оболочка». Ни один мой тест обеих задач не содержал команды, которая САМА уходит в другой каталог. Поле cwd есть каталог ДО выполнения, поэтому cd ПРОЕКТ && python helper.py превратил блок в разрешение — под-обнаружение, запрещённое моим же AC. Правило: когда берёшь факт среды из события, спроси, может ли он устареть ВНУТРИ обрабатываемого объекта; если да — не выбирай один вариант, а падай в сторону блокировки объединением.
