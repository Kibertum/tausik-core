Внешнее L3 #38 (opus-5) на закрытую next-version: `git rev-list --all -- FILE` перечислил 2 коммита из 4 достижимых. Слияние `-s ours` TREESAME своему родителю, обход идёт только к нему, и версия манифеста v3 с проигравшей стороны была достижима, не перечислена и выдана повторно (§13.4.1). Флаг --full-history снимает упрощение, число процессов не меняется, живой репозиторий отвечает те же 17. Правило: выбирая команду git по названию флага, прочитай её семантику упрощения; синтетика обязана включать слияние с отбрасыванием стороны, а не только ветку без слияния. Вторая поправка того же ревью: «55 мс при любом n» считало только процессы — сквозной замер 125–151 мс, линейно по числу коммитов из-за YAML-разбора блобов; цифру стоимости меряй сквозным вызовом, а не суммой подпроцессов.
