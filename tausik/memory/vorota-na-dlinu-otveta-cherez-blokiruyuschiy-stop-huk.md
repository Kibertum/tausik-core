Approach: Ворота на длину ответа через блокирующий Stop-хук
Reason: Прецедент keyword-detector-self-trigger-loop, воспроизведённый на живом транскрипте: Claude Code отдаёт reason блокировки Stop как ошибку хука и ХОД УМИРАЕТ БЕЗ ВЫВОДА. Для длинного ответа это строго хуже болезни — пользователь не получает вообще ничего вместо того, чтобы получить многословное. Блокировка Stop остаётся законной только там, где текущий вывод не жалко: drift-guard «сейчас напишу код» без активной задачи. Enforcement формы ответа обязан стоять ДО составления ответа: правила, читаемые каждый ход (кэшируемый префикс), плюс храповик на замере — отказ релиза, а не отказ ответа.
