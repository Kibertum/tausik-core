ЗАКРЫТО В #125. Дефект (#229, тезис 1.8): правка scripts/*.py проходит зелёный набор и НЕ доезжает до исполняемой копии профиля (.claude/scripts/ и др.), откуда грузятся хуки и MCP. Тесты импортируют из scripts/ — зелено там, где проверяют, старое там, где работает. Ловил только doctor WARN, который не входит ни в набор, ни в гейты.

РЕШЕНИЕ — зарегистрированный блокирующий гейт bootstrap_drift на task-done (образец gate_renar_drift.py: запись в default_gates + ветка в gate_runner + отдельный модуль под filesize-лимит). Три принципа, каждый обоснован:

(1) ПАДАТЬ, НЕ ПЕРЕСОБИРАТЬ. Авто-ре-bootstrap внутри гейта = мутация состояния, которое гейт оценивает — ровно класс дефекта _handle_gate_toggle из этой же сессии (операция объявлена проверкой, исполняется записью). Правка, не доехавшая до копии, НЕ вступила в силу; блокировать закрытие справедливо. Сообщение обязано НАЗЫВАТЬ файлы + точную команду.

(2) ВСЕ ПРИСУТСТВУЮЩИЕ ПРОФИЛИ, отсутствие профиля — НЕ дрейф. Функция различает None (нет источника, сравнить нельзя) и [] (сравнили, чисто — ВКЛЮЧАЯ 'профилей нет вовсе': свежий клон/CI, профили в .gitignore). Гейт на [] и None ПРОХОДИТ — иначе падал бы у всех без пяти IDE и его отключат первым.

(3) КОМАНДА ПОЧИНКИ — 'bootstrap.py --ide all', НЕ '--update'. Вскрыто гейтом на себе: наивный '--update' префикс-матчит '--update-deps' и с дефолтом '--ide claude' чинит ТОЛЬКО claude; четыре профиля отставали. Гейт, называющий неверную команду, бесполезен.

harness/ ВЫНЕСЕН отдельной задачей: раскладывается в профиль не вербатим (harness/claude/* -> .claude/{mcp,skills,...}), сравниватель по именам был бы второй копией логики bootstrap (конвенция #249). Правильный путь — заставить сам bootstrap сообщать расхождения (режим --check), оракул = код раскладки.

ТЕСТ — на ФУНКЦИЮ, синтетический tmp_path, НЕ на реальные профили: они в .gitignore, тест против них выродится в вечный skip на клоне (тот самый мёртвый тест, что гейт и ловит). Доказан внесённым дрейфом: правка source без пересборки роняет гейт с именем файла.
