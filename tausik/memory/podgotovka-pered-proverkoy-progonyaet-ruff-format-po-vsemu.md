Approach: Подготовка перед проверкой прогоняет ruff format по всему дереву
Reason: На первом же настоящем прогоне переформатировала 90 файлов, включая те, что намеренно держит список ruff_format.legacy_unformatted — храповик, который только уменьшается, был бы молча опустошён удобством. Правка файлов, которых никто не объявлял, есть нарушение Правила 2 с чёрного хода: подготовка обязана получать объявленную область и пропускаться ВСЛУХ, когда области нет. Плюс второй урок той же цены: сама починка не действовала, пока не была развёрнута, — первые два прогона исполняли старую копию из .claude/ и снова правили 90 файлов.
