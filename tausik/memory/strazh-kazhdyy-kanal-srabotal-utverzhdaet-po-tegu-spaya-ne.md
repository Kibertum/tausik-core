Ревью #208 (запись #16) на починку #540: спай патчил три канала, но «канал сработал» узнавал по форме пути (.db, proj/.git) — форма пути говорит, КАКОЙ БИЛДЕР писал, а не ЧЕРЕЗ КАКОЙ СПАЙ прошло. Итог: снятие патча open оставляло тест зелёным (24 события записи не наблюдались), а переименование каталога билдера краснило его ложно. Правило: запись спая несёт имя канала, тест утверждает множество тегов; на каждый канал — мутация «патч снят -> красный по имени канала» и обратная «литерал билдера переименован -> зелёный». Дисклеймер «что не смотрится» пишется по ЗАМЕРУ вызовов (os.mkdir 83, os.open 13 и всё DEVNULL), а не по догадке.
