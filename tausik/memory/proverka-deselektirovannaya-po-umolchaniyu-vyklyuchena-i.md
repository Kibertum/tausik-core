addopts в pyproject содержит -m 'not slow'. Под этой меткой стоял ХРАПОВИК мёртвых символов, поэтому каждое «полная лента зелёная» означало ленту без 157 тестов в 17 файлах: сам храповик, весь bootstrap, интеграция MCP, CLI.

ЦЕНУ МЕТКИ НАДО МЕРИТЬ, А НЕ ПРЕДПОЛАГАТЬ. Замер по --durations: 128 с один тест стресса, 290 с покрытие скиллов, 48 с bootstrap_real — и 6,5 с весь файл храповика, 2,9 с справка по скиллам. Метка ставилась на ощупь и осталась на дешёвом.

ПРАВИЛО: храповик не живёт в ленте, которую деселектирует default. Если проверка охраняет НОЛЬ (мёртвые символы, протухшие ссылки, размер файла), она обязана идти в той ленте, которую запускают по привычке, иначе ноль держится только на памяти агента. И отчёт о прогоне обязан называть, сколько тестов ДЕСЕЛЕКТИРОВАНО, а не только сколько прошло: 11592 passed и 157 deselected — разные утверждения.
