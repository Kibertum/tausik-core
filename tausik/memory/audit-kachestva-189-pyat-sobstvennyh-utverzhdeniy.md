Развёртка SENAR Rule 9.5 в сессии #189 (пять сессий без аудита). Проверялись не тексты закрытий, а УТВЕРЖДЕНИЯ задач — вызовом.

ОХВАТ. (1) `tausik audit evidence` по всей базе: 1239 закрытых задач, 515 со ссылкой на тест, 2756 ссылок / 1009 уникальных, разрешаются 968, ROTTED 16, NEVER_EXISTED 25, UNKNOWN_HISTORY 0. (2) Домер четырёх заявленных издержек задачи four-byte-identical-copies-of-the-harness. (3) Замер публичной линии и тегов. (4) Проверка обоих гейтов задачи verify-mypy-verify-dict мутацией.

ЧТО ОКАЗАЛОСЬ НЕВЕРНЫМ В СОБСТВЕННЫХ ЗАПИСЯХ (пять утверждений):
1. «Гейт размера считает зеркала» — нет: run_filesize_gate проверяет только переданный список, а зеркала гитигнорятся и в индекс git не попадают.
2. «Поиск индексирует зеркала» — нет: 0 чанков под .claude/.cursor/.qwen/.kilo/.opencode в rag.db.
3. «Убитых в skills_coverage девять» — восемь; 8+4+2=14, прежняя запись давала 15.
4. «Push веткой привезёт приватный архив» — дерево бухгалтерии уже опубликовано: github/main несёт 2438 файлов под tausik/ против 2469 приватных; из трёх названных утечек имена чужих проектов уже публичны, хост и локальные пути — нет.
5. «Разбор вариантов scope-гейта надо принести от потребителя» — верно, но задача у потребителя уже ЗАКРЫТА, вариант выбран и реализован патчем 0004.

ДВА НОВЫХ ДЕФЕКТА, НАЙДЕННЫХ АУДИТОМ: rag-index-never-prunes-deleted-paths (62 мёртвых пути в индексе, search_code первым результатом отдаёт несуществующий файл) и audit-evidence-counts-illustrative-names-as-citations (корзина NEVER_EXISTED в основном шум из прозы).

ЧТО ЗДОРОВО: ROTTED 16 из 1009 уникальных ссылок — 1.6% гнили за 1239 закрытий; UNKNOWN_HISTORY ноль, то есть история git отвечает на каждый вопрос.
