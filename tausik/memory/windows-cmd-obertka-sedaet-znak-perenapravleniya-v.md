Windows: зови POSIX-обёртку .tausik/tausik из bash, НЕ .tausik/tausik.cmd из python. Обёртка .cmd передаёт аргументы через cmd.exe, который оставляет знак «больше» УПРАВЛЯЮЩИМ: стрелка внутри текста становится перенаправлением вывода. Замерено в #200 на handoff смены: в корне репозитория появился посторонний файл с именем следующего слова, из сохранённого JSON пропал кусок от знака «больше» до пробела («SCHEMA_VERSION 48-» вместо «48 на 49»), а кириллица приехала суррогатами U+DC81. Команда вернула НОЛЬ и отрапортовала успех — порча обнаружилась только сверкой прочитанного обратно.
РАБОЧИЙ СПОСОБ: положить аргумент в файл и передать как "$(cat файл)" в .tausik/tausik из bash. Проверено на том же handoff: сохранилось дословно, суррогатов ноль.
ОБЩЕЕ ПРАВИЛО, ШИРЕ ЭТОГО БАГА: записав длинный текст через CLI, ПРОЧИТАЙ ЕГО ОБРАТНО и сверь — особенно передачу смены и всё, что уходит наружу. Успешный код возврата не есть свидетельство того, что аргумент доехал дословно. Заведено tausik-cli-cmd-wrapper-eats-redirect-chars.
