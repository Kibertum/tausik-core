Approach: Починить плавающий отказ test_unknown_path_is_404 укреплением ожидания готовности сервера
Reason: Гипотеза отвергнута чтением кода, а не прогоном: _wait_until_serving уже дедлайн с условием, ловит оба семейства исключений и падает громко; в его docstring записан прежний замер этой же гонки. Наблюдённый отказ был провалом УТВЕРЖДЕНИЯ (сервер ответил не 404), а не ошибкой фикстуры, поэтому ожидание тут ни при чём. Править по догадке нельзя: 24 прогона в изоляции дают ноль отказов, воспроизвести нечем, и любая правка была бы зелёной по той же причине, по которой зелен цикл.
