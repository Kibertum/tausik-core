Спека архива задач и Rollback задачи два релиза называли архивацию 'обратимой командой'. Команды не было: grep по scripts/ harness/ docs/ дал 25 живых упоминаний archived_at, все читающие или ставящие метку, ни одного UPDATE ... SET archived_at = NULL. Справочник CLI при этом честно писал 'НЕОБРАТИМО: команды нет' двумя строками ниже прозы про обратимость — два противоположных claim в одном файле никто не сверял. ЧИНИТСЯ НЕ ТЕКСТОМ: tausik hygiene unarchive (слаг или --archived-within, dry-run по умолчанию, двигается только archived_at) плюс тест, который ЧИТАЕТ claim из спеки и требует, чтобы названная команда разбиралась парсером. Фраза больше не переживёт код. Асимметрия с памятью объявлена: у памяти отката нет намеренно, архивация памяти гасит рёбра графа valid_to, и снятие признака их не вернёт.
