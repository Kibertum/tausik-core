Смена #277: verify_scope_honesty отказывал по окну 'изменено с начала задачи'. Тестовый помощник _runner отвечал на git log и git diff — и этого хватало, потому что кода, спрашивающего git status, не существовало. Когда отказ сузили до незакоммиченного подмножества, ЧЕТЫРЕ существующих теста стали зелёными по новой неверной причине: настоящий git не знает выдуманных путей, поэтому подмножество пустое и отказа нет. ОБЩИЙ ПРИЁМ: если проверка спрашивает git НЕСКОЛЬКИМИ командами, помощник обязан отвечать на все, а умолчание должно воспроизводить прежнее допущение — иначе прежние тесты меняют предмет молча. Признак беды: тест зеленеет сразу после сужения условия, которое он должен был бы поймать.
