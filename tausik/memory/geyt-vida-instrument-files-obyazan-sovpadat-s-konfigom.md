ПРАВИЛО. Прежде чем объявить гейт как `<инструмент> {files}`, спроси: есть ли у инструмента СВОЙ набор источников в конфиге проекта? Если есть — подстановка изменённых файлов создаёт ВТОРОЙ источник истины о том, что проверяется, и вердикт гейта расходится с вердиктом инструмента.

ЗАМЕР, НА КОТОРОМ ПРАВИЛО РОДИЛОСЬ (сессия #191, задача mypy-gate-measures-differently-than-mypy-itself). pyproject.toml: files = ["scripts", "harness/claude/mcp/project"], exclude = ["scripts/hooks/"].
  python -m mypy                    -> Success, 341 файл, 0 ошибок
  python -m mypy tests/conftest.py  -> 3 ошибки (import-not-found service_gates:71, backend_schema:207, no-any-return:212)
Явно переданный файл проверяется ВНЕ набора источников, поэтому импорты, резолвящиеся в штатном прогоне, перестают резолвиться. `exclude` к явным аргументам тоже НЕ применяется — намеренно исключённое проверяется наравне со всем.

ХУДШЕЕ СВОЙСТВО, РАДИ КОТОРОГО ЗАПИСЬ И СДЕЛАНА: ложное срабатывание УСЛОВНО. Тот же conftest.py, проверенный ВМЕСТЕ с любым scripts/*.py, выходит ЗЕЛЁНЫМ — соседний аргумент возвращает инструменту путь к пакету. Вердикт гейта зависел от того, что ещё случайно попало в коммит. Такой гейт не проверяет, а гадает, и в передачах его гадание читается как устойчивый факт о коде: три ошибки несколько смен подряд передавались как «дорелизный долг типов», хотя чинить в типах было нечего.

ЧИНИТСЯ СНЯТИЕМ ВТОРОГО ИСТОЧНИКА, А НЕ ПОДКРУЧИВАНИЕМ ПЕРВОГО. Команда стала просто `mypy`. Цена замерена: 0.46 s против 0.19-0.42 s, до +0.27 s; коммит без .py стоит 0.00 s. Взамен гейт ловит СТРОГО БОЛЬШЕ — правка в одном модуле, ломающая типы в другом, пофайловому прогону невидима.

СЛЕДСТВИЕ ДЛЯ РЕЕСТРА ГЕЙТОВ: `file_extensions` объявляет, КОГДА гейт применим, и это не зависит от наличия {files} в команде. До #191 фильтрация применялась только при подстановке, то есть у гейта без неё объявление молча ничего не значило.

ГДЕ ЕЩЁ СПРОСИТЬ ТОТ ЖЕ ВОПРОС: у всякого гейта вида `<инструмент> {files}`. Сегодня их три — ruff, mypy, bandit. У ruff собственного `files=` нет, расхождения не возникает; bandit проверить не успели.

Тот же класс, что [[#277]] (адрес из одного источника, содержимое из другого). Связано: [[#440]].
