# TAUSIK 1.11.7 — memory-only Cursor playbook and task rename

memory-only keeps a light backlog (canon B): epic, story, and task stay as
work accounting while session, verify, and QG walls stay off the default path
unless the owner asks for `full_path`. Bootstrap deploys `tausik-memory`;
`tausik_memory_brief` returns the playbook in one call. `tools/list` annotates
disabled profile tools. Cursor economy is documented as rounds + surface
(multi-project), not cache polish — Codex numbers are not relabeled as Cursor.

`task rename` / `tausik_task_rename` move a published slug with every referring
column in one transaction (schema-derived referrers, `foreign_key_check`,
projection cleanup). The release CI gate stays minutes: Windows is nightly,
not per-push.
