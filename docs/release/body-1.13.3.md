# TAUSIK 1.13.3

TAUSIK 1.13.3 makes protected memory preflight practical for agents and keeps
GitHub release bodies under `docs/release/`.

- `/commit` documents the exact `tausik_memory_preflight` ritual: inspect, then
  acknowledge; Cursor `Shell` binding; conflict handling via `reason:<seq>`.
- A missing token prints that remediation in one line.
- EN/RU MCP docs add a short agent checklist — no need to reverse-engineer
  `memory_preflight.py`.
- Release bodies live at `docs/release/body-<version>.md`; historical root files
  relocate there.
