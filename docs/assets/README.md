# The TAUSIK mark

Two renderings of one mark — a woman with a hairpin in a rounded frame — and
where each one goes. The frame and the near-black ground are part of the mark;
neither file is transparent.

| File | Rendering | Use it for |
|---|---|---|
| `tausik-logo.png` | monoline: one orange stroke on near-black | **The logo.** The front pages — `README.md` / `README.ru.md` on GitHub and GitLab — the docs index (`docs/README.md`), the repository's social preview and avatar, a release page, a favicon, a sticker, anything printed in one colour. A single stroke stays crisp at 200 px and at 64 px, and it does not compete with the page it sits on. |
| `tausik-logo-full.png` | full colour: black hair, cream face, red-orange kimono and frame | Kept, not placed. Where a full-colour rendering is wanted — a poster, a print with mass — this is it; it is not on any page of the repository. |

The owner's decision of 2026-09-14: the monoline is the main logo; the colour
rendering stays as `-full`. Before that the pages carried the colour and the
docs index the line.

Sources are the owner's originals (2026-09-13), cropped to the frame with a
40 px margin on a square canvas; PNG so nothing is re-encoded from here on.
