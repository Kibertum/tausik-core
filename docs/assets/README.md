# The TAUSIK mark

Two renderings of one mark — a woman with a hairpin in a rounded frame — and
where each one goes. The frame and the black ground are part of the mark;
neither file is transparent.

| File | Rendering | Use it for |
|---|---|---|
| `tausik-logo.png` | full colour: black hair, cream face, red-orange kimono and frame | The front pages — `README.md` / `README.ru.md` on GitHub and GitLab, the repository's social preview and avatar, a release page. It has mass: it reads at 200 px on a light or a dark page and still reads at 64 px. |
| `tausik-mark.png` | monoline: one orange stroke on near-black | Secondary and small placements — the docs index (`docs/README.md`), a dark-theme site header, a favicon, a sticker, anything printed in one colour. A single stroke stays crisp where the full-colour fill would blur, and it does not compete with the page it sits on. |

Rule of thumb: the reader's FIRST meeting with the project gets the colour;
every repeat meeting gets the line. Do not put both on one page.

Sources are the owner's originals (2026-09-13), cropped to the frame with a
40 px margin on a square canvas; PNG so nothing is re-encoded from here on.
