# TAUSIK CLI — Справочник команд

<!-- doc-map: reader=user; zone=core-surface -->

Все команды запускаются через обёртку: `.tausik/tausik <команда> [подкоманда] [аргументы]`.
На Windows обёртка — `.tausik/tausik.cmd`. Тот же surface также доступен через MCP (`tausik_*` инструменты); см. `mcp.md`.

## Рабочий набор

Поверхность — 54 команды верхнего уровня, и читать их подряд незачем. В базе этого проекта
записано 6930 вызовов поверхности TAUSIK, из них 74 разных инструмента; **двенадцать команд
ниже дают 81% всех вызовов**, двадцать восемь — 95%. Замер описывает эту работу, а не
предсказывает вашу: у проекта с другим укладом набор будет другим. Но начинать стоит отсюда.

| Команда | Зачем | Доля вызовов |
|---|---|---|
| `task update` | поправить поле начатой задачи — критерии, бюджет, область | 11,3% |
| `task log` | записать шаг: чем это кончилось и что стало известно | 10,4% |
| `task start` | открыть работу; здесь же проверяются цель и критерии приёмки | 10,2% |
| `task add` | завести задачу — находку, дефект, следующий шаг состава | 9,0% |
| `task show` | прочитать задачу целиком: критерии, область, журнал | 7,5% |
| `task done` | закрыть с квитанцией проверки | 6,1% |
| `memory add` | записать паттерн, соглашение или тупик проекта | 5,6% |
| `task step` | отметить фазу внутри задачи | 5,2% |
| `decide` | записать решение и то, что оно отвергло | 4,9% |
| `verify` | прогнать шлюзы по области задачи и получить квитанцию | 4,6% |
| `update-claudemd` | обновить динамическую часть `CLAUDE.md` | 3,4% |
| `session handoff` | оставить следующему агенту состояние смены | 2,9% |

Полные флаги каждой — `.tausik/tausik <команда> --help`. Справка живёт в парсере, а не на
этой странице: страница устаревает молча, `--help` — нет.

> **Аргументы со знаками `>`, `<`, `&`, `|` на Windows.** `.cmd`-обёртка запускается через `cmd.exe`, а он разбирает эти знаки как операторы **до** того, как батник начнёт работу — даже когда вызывающий передал аргумент списком, без оболочки. Замер: из девяти враждебных аргументов пять портились, и два портились **молча** — `48->49` доезжал как `48-` с кодом возврата 0, а вывод уходил в посторонний файл `49`; `a&b` доезжал как `a`, а хвост `b` исполнялся как команда. Так однажды сохранился обрезанный handoff, и команда отрапортовала успех.
>
> Теперь такой вызов **падает с кодом 3** и печатает в stderr, что было на командной строке и что дошло до процесса, называя посторонний файл, если `cmd.exe` успел его создать. Молчаливого сохранения испорченного значения больше нет.
>
> Что делать: вызывайте POSIX-обёртку `.tausik/tausik` из bash (она передаёт `"$@"` и потерять аргумент не может) либо MCP-инструменты — ни то, ни другое не идёт через оболочку. Если перенаправление было **намеренным** (например, скрипт пишет `cmd /c "tausik.cmd status > out.txt"`), снимите охрану переменной `TAUSIK_CMDLINE_GUARD=off`.
>
> Перенаправление, набранное руками в интерактивной консоли (`tausik status > out.txt`), охрана не трогает: там `%CMDCMDLINE%` содержит только строку запуска самой оболочки и аргументов не называет.
