# TAUSIK 1.12: восстановимый handoff контекста хоста

<!-- doc-map: reader=user; zone=release-notes -->

## 1.12.0 — 2026-11-11

TAUSIK 1.12.0 устраняет тупик восстановления на `HOST_CONTEXT_HARD`. Когда
незавершённая задача достигает потолка контекста потока хоста, доверенная
граница теперь сохраняет готовый checkpoint с точной командой
`.tausik/tausik task start <slug> --package`, отзывает старую execution lease и
закрывает этот поток. Повторный Stop возвращает `ALLOW_HANDOFF`, поэтому работа
продолжается в новом потоке без повторного чтения всей переписки.

Восстановление не возвращает полномочия исчерпанному потоку. Записи реализации,
явные попытки MCP- или CLI-handoff, остальные защищённые мутации и смешанные
пакеты запросов остаются заблокированы. Checkpoint привязан к точным project,
host, thread, session и task lease; неоднозначная authority закрывается
безопасно.

Поведение покрыто сценариями живой и истёкшей lease, fresh-process регрессией
Stop, глубоким независимым review и штатными релизными проверками.
