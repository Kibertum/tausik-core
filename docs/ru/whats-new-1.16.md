# TAUSIK 1.16.2: завершение чата Codex без принудительного продолжения

<!-- doc-map: reader=user; zone=release-notes -->

## 1.16.2 — 2026-11-27

TAUSIK 1.16 разделяет завершение ответа и разрешение менять проект.
Stop в Codex больше не запускает новый ход модели из-за незавершённой задачи
или слов в запросе проверки готовности. Детектор фраз убран из Codex Stop.
Старые регистрации Stop безопасно завершаются до перезагрузки IDE.

Порог контекста по умолчанию рекомендательный: предлагает сохранить checkpoint,
не отзывает lease и не требует нового чата. Для намеренно строгого режима
можно явно задать `host_context_budget.enforcement` равным `hard`.
Старые машинные инструкции checkpoint при чтении актуального handoff следуют
текущей политике. Исторические записи и указания владельца сохраняются.

PreToolUse, native identity, execution leases, memory preflight, явные бюджеты
задач и QG-0/QG-2 продолжают действовать. Завершение чата не разрешает запись
файлов или выполнение защищённых команд.

Также исправлены привязка preflight для Shell/PowerShell, распознавание имени
CLI внутри поисковых аргументов, определение модели по журналу своего чата
и обработка Windows кэша байткода виртуальных окружений WSL.

## Обновление

Обновите checkout фреймворка до `v1.16.2`, повторите bootstrap для используемых
хостов и один раз перезагрузите IDE для загрузки новых MCP-модулей и навыков.
Для проекта только с Codex:

```powershell
py .tausik-lib/bootstrap/bootstrap.py --project-dir . --ide codex --no-detect
./.tausik/tausik.cmd doctor
```

В проекте с несколькими хостами сохраните настроенный список и обновите каждый
профиль. Перед удалением локальных патчей проверьте, что они вошли в релиз.
