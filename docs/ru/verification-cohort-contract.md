# Контракт пул-верификации (зеркало; полный текст — EN)

Спецификация: `docs/en/verification-cohort-contract.md` (SPEC
`verification-cohort-contract`, ARCH, 1.0-draft). Ниже — русское зеркало
ключевых правил и измеренного доказательства.

## Правила (кратко)

- Identity когорты: SHA-256 по канонической сериализации — сортированное
  членство, фингерпринты задач, СТАТУСЫ участников, union scope, хэши
  контента, сигнатура гейтов, выбранные тесты, состояние репозитория.
- Один прогон гейтов на объединённый скоуп; исполнение делегируется в
  `run_verify_for_task` — все кэш-гарды однозадачной линии наследуются.
- Переиспользование отменяется ИМЕНОВАННЫМ инвалидатором: membership-drift /
  missing-evidence / task-edits / member-status-drift / gate-signature-drift
  / security-sensitive-scope / uncertain-dependency-mapping. Отказ обязан
  назвать причину. Отказывается только ЗЕЛЁНОЕ доказательство: красный
  предшественник с новой identity — следующая попытка, а не тупик.
- Красное продолжение: прошлые фейлы ∪ тесты, затронутые дельтой
  (`required_after_red`, чистая функция).
- `story/epic done --verify-handle` закрывают участников и родителя ОДНОЙ
  транзакцией на точном рецепте; дрейф делает handle просроченным, частичное
  закрытие откатывается целиком.
- Однозадачный `verify --task` и его handle не изменились; пул — opt-in.

## Измеренное доказательство (сессия #295)

- Базовая линия (позадачные прогоны, записаны): **34 исполнения / 1492.1 с**
  на 7 задач (в среднем 4.9 прогона на задачу).
- Пул (`verify --tasks`, все семь): **1 исполнение по union-скопу из 44
  файлов, 314.6 с вместе с подготовкой. Экономия: в 21.4 раза меньше
  исполнений, в 4.7 раза меньше времени (~19.6 мин).**
- Красный путь тоже живой: прогоны #3587/#3588 ушли в красный на
  подготовительных гейтах, #3589 после исправления — зелёный.

Когда остаются нужны позадачные affected-тесты: закрытие одной задачи,
security-чувствительные скоупы, неопределённый маппинг зависимостей. Пул —
когда ≥2 review-ready задач делят линию, прежде всего релизные истории.
