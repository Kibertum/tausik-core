# Kilo/GLM: протокол адаптера расхода для 1.11

Дата замера: 2026-10-01. Выбранный GLM-хост: Kilo Code.

## Наблюдаемая поверхность

- Установлены расширение VS Code и bundled CLI Kilo 7.8.1.
- Официальная документация Kilo разрешает read-only запросы к локальной SQLite-базе
  `kilo.db`: <https://kilo.ai/docs/code-with-ai/agents/session-history>.
- Исходный код Kilo хранит `input`, `output`, `reasoning`, `cache.read` и
  `cache.write` как пять раздельных величин: <https://github.com/Kilo-Org/kilocode/blob/main/packages/opencode/src/session/session.ts>.
- До acceptance-smoke в живой базе было 6 сессий и 234 assistant-записи. Итоги всех
  сессий точно совпали с их суммой; завершённых ответов GLM было 0.

## Контракт TAUSIK

Адаптер выбирает SQL-ом только версию хоста, provider/model, время и токенные
счётчики. Идентификаторы проекта, сессии и ответа хэшируются. Промпты, tool payload,
ключи и исходные пути в `.tausik/usage-kilo.sqlite` не записываются.

Общий `input` равен `input + cache.read + cache.write`; общий `output` равен
`output + reasoning`. Отсутствующая часть делает соответствующий итог неизвестным.
Повторный отчёт читает ноль неизменённых assistant-строк, а resume добавляет только
новые или изменённые ответы. Агрегаты Kilo дают независимую проверку суммы.

CLI `metrics tokens --host kilo --json` и MCP `tausik_metrics(host=kilo)` вызывают
один сервис. Отсутствующая база и несовместимая схема возвращают явный unavailable,
а не нулевой расход.

## Граница доказанного

Проверены реальный формат Kilo, инкрементальный resume, отсутствие дублей и точная
сверка на живой не-GLM сессии. Намеренный вызов `~z-ai/glm-flash-latest` создал
GLM-запись версии Kilo 7.8.1, но Kilo Gateway вернул HTTP 402 до генерации: баланс
кредитов равен нулю, а модель не бесплатна. Отчёт различает одну ошибочную GLM-запись
и ноль завершённых GLM-ответов. Квота подписки, стоимость и экономия не выводятся:
локальная база их не доказывает. Живой цикл start/report/verify/resume именно на GLM
не заявляется пройденным до появления кредитов или настроенной подписки z.ai.
