# TAUSIK 1.11.1

TAUSIK 1.11.1 hardens proportional assurance, natural-work cost telemetry,
session freshness, and the public release snapshot. The release keeps the
economy claim bounded: accepted-task response rounds have not met the target,
so no savings claim is made.
